# 無限迷宮アビス v0.8 — 魔法店・回数制魔法・魔法器

単一HTMLで動くオフラインRPG。GitHub Pages: https://tenukilab.github.io/infinite-abyss/

## v0.8 魔法システム

- 拠点に「魔法店」を追加。購入・使用回数回復・魔法器への封入と取り出しができる。
- 魔法は職業制限なし。ファイター等でも同じ性能。1種類の魔法、または魔法器を装備する。
- 使用回数の最大値は**5000**、店売り魔法は初期**3000回**。発動した魔法だけ1回消費する。単体で装備しても魔法器に詰めても同じ個体の使用回数を使う。
- 魔法店での回復対象は**残り800〜2999回**の魔法に限られる。回復上限は**3000回**。残り799回以下は**魔法店では回復・合成できない**（後日別の回復手段を追加予定）。
- 魔法は**1ターン最大1回**。魔法器に入っている全魔法を個別に確率抽選し、当選が複数なら当選魔法から**均等確率**で1つ選ぶ。抽選だけで選ばれなかった魔法は消費しない。
- 魔法器の発動倍率は**全内包魔法**の判定に適用。基準運8なら基本20%の魔法は魔法石で20%、太陽石で60%。運の微補正は倍率の前に計算。
- ジョブスキルと武器熟練技は魔法と別処理。魔法はターン先頭に発動し、通常攻撃は従来どおり行う。魔法発動回数は素早さによる行動回数増加に左右されない。

## 魔法店のラインナップ

| 名称 | 価格 | 内容 |
| --- | ---: | --- |
| ファイアー | 3,600G | 基本発動率20%。敵に防御無視の固定500ダメージ |
| ヒール | 2,500G | 基本発動率20%。自分のHP300回復（最大HP超過なし） |
| ビール | 4,200G | 仮発動率20%。1戦闘1回限りで命中率半減、最終攻撃ダメージ1.2倍 |
| 魔法石 | 1,400G | 魔法2つまで封入、発動率1倍 |
| 太陽石 | 8,500G | 魔法3つまで封入、全内包魔法の発動率3倍 |

ビールの命中率半減は最終命中率×0.5で計算。最終攻撃ダメージ×1.2はジョブスキル、魔力暴走、武器熟練技を計算した後の攻撃に適用し、固定500ダメージのファイアーには適用しない。ビールの効果はその戦闘中持続し、同一戦闘で再発動・再消費しない。

回復価格はファイアー・ヒールが不足回数×0.6G、ビールが不足回数×0.8G（端数切り上げ）。購入より回復が割安。魔法器への封入は無料。封入時は残り800回以上が必要、取り出しは799回以下でも可能。魔法と魔法器は複数購入できる。
