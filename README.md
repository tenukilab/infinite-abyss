# 無限迷宮アビス — チャットログ再現版 v0.1

チャット上で遊んだ「無限迷宮アビス」を、画像・外部ライブラリなしで遊べる単一HTMLのブラウザゲームにしました。

## 遊び方

1. `index.html` をブラウザで開きます。PCではダブルクリックでも動きます。
2. **探索**：階層を選び、1/5/10/20/30戦を実行。HP撤退条件を設定可能。
3. **装備**：ドロップした装備を装着・売却。能力値が即座に反映されます。
4. **拠点**：宿屋でHPを全回復（20G）、鍛冶屋で装備を強化。
5. **記録**：ゲームのログ、JSONセーブデータのエクスポートとインポート。

初回は**チャットログ終了時点**（Lv.9／第3層／HP167/196／EXP155/265／908G／ATK53／DEF11／暴走率15％）から再開します。
「記録」タブの「最初から」を押すとLv.1から新しく遊べます。

スマホでは、GitHub Pages等の静的ホスティングに置くとブラウザから便利に遊べます。保存先はブラウザの `localStorage` です。ブラウザのデータ削除・別端末への移動などに備えてJSONでセーブを書き出してください。iOSの「ファイル」アプリのHTMLプレビューでは、JavaScriptや保存の挙動が制限される場合があります。

## 技術

- 純粋なHTML/CSS/JavaScript、外部パッケージ・画像・通信なし
- シードを保持するxorshift32疑似乱数（新規戦闘の再現性を確保）
- `localStorage` 自動保存・JSON入出力
- スマートフォン向けレスポンシブUI
- ダメージ、経験値、装備能力値を1つの計算ロジックから算出

## 実装済み

- 第1〜5層、雑魚敵、5層ボス「腐敗した騎士」
- オート周回、HP閾値で撤退、レベルアップ
- ランダム装備ドロップ（コモン〜レジェンダリー）、ランダム付与効果
- 8部位の装備、蒼火の杖＋屍術師の首飾り等の固有効果
- G経済、宿屋、試作鍛冶屋、鉱石、売却
- 過去に確定した装備とLv.9のプレイヤー状態を初期データに反映

## ログ再現の限界・仕様の補完

**チャット上で確定した要素**：魔術師の初期値、LvUP補正、魔力暴走10%×2.5倍、宿屋20G、1層40%/2層45%/3層50%の装備ドロップ、最終ボスの名称、初期アイテムの能力値、ログ終了時点の能力値・所持金・経験値・HP。

**今回のアプリで補完した要素**：4〜5層の敵能力や装備率、敵の出現重み、レアリティ別確率、階層解放戦闘数、レベル10以降の経験値表、死亡時の金銭ペナルティ、強化レシピ、鉱石ドロップ、ランダム付与値。

会話の過去の抽選結果が「固定シード」と表現されていても、実際にそこから乱数列を再現するための完全なアルゴリズムや実行ログは残っていません。今回のアプリは**過去の状態を固定スナップショットとして継承**し、そこから新しいシードで実行を始めます。過去の47戦を同じ抽選で再シミュレーションしたわけではありません。
