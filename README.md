# 無限迷宮アビス v0.13 — ボスの特殊行動・ウォール・ジョブマスター

ブラウザ型のオフラインRPG。`index.html`単体で動作し、セーブは端末の`localStorage`に保存されます。

- 公開ページ：https://tenukilab.github.io/infinite-abyss/
- **v0.12のセーブも初期化しません。** 能力値、熟練度、装備、魔法、魔の森・カジノの進行・戦闘記録を維持します。

## v0.13 の変更

### ボスの暴走

- 通常迷宮・魔の森の**すべてのボス**は、HPが50%以下になると暴走し、以後の攻撃ダメージが1.5倍（仮数値）。1戦闘1回だけ発動。
- 魔の森50階の原初王は、毎ターン20%で**麻痺**（次の1ターン行動不可、ボスの次の攻撃は必中）を発動。
- 同じく毎ターン20%で**原初の壊撃**（命中率10%・ダメージ10倍）を発動。
- 麻痺と壊撃は**独立した20%の抽選**。両方当選したターンは麻痺が先に発動し、その直後の壊撃が必中になる。麻痺のみの場合はそのターンの通常攻撃を行わない。
- 暴走中の壊撃は倍率15倍。壁は防御計算後の被ダメージを吸収する。
- ターンごとの特殊行動や壁の増減は、魔の森の戦闘記録から確認可能。

### 魔法「ウォール」

- 新しい魔法。発動時、最大HPと同じ量の壁を張り、**最大HPの3倍まで重ねがけ可能**。壁はHPより先にダメージを吸収し、**戦闘ごとにリセット**する。
- 暫定発動率20%。最大5000回。魔法石・太陽石に封入できる。
- **販売不可（将来のドロップ専用品）**。ただし残り800回以上の場合、魔法店で回復・魔法器への合成が可能。店で回復できるのは3000回まで。
- 従来の開発用レーヴァテイン・玄武の鎧を両方持つセーブへ、初回移行時に**ウォール5000回を1個だけ付与**。自動装備なし。新規セーブには付与しない。ユーザー認証機能がないため、所有アイテムによる仮判定。

### ジョブマスター

- 各ジョブの**ジョブLv60でMASTER認定**。マスター済みの職数も表示。
- 今後追加する上級職の転職条件として、マスター済み職を指定できる構造を追加。現在の基本4職の条件はなし。
- **マスター専用の第2パッシブ**は各ジョブに将来設定できる枠のみ用意。具体的な効果は未設定・未発動。
- パッシブ発動は、将来、**現在就いているジョブ**に限定する。魔術師の既存「魔力暴走」は維持。

## v0.12 の変更履歴

### 装備に基本攻撃力・基本防御力を追加

- 武器：`攻撃力 = baseAttack + 熟練度 × 5`。攻撃ダメージの基本式に加算し、その後スキル・魔力暴走・熟練技等の倍率を適用。
- 胴防具：`防御力 = baseDefense + 熟練度 × 1`。頭・手・足の防具にも固定基本防御力を設定（熟練度は付けない）。
- 敵からの基本ダメージから装備防御力を差し引いてから乱数・スキル軽減を適用。最低被ダメージ1。魔法ファイアーの固定ダメージは変更なし。
- レーヴァテイン：基本攻撃12,000＋熟練2,000×5＝**22,000**。
- 玄武の鎧：基本防御2,500＋熟練2,000×1＝**4,500**。
- 仮の店売り基本値：武器攻撃30、頭防御8、胴防御15、手防御5、足防御6。カジノ景品武器は攻撃750。今後調整可能。

### オーラの結晶・アクセサリー枠

- `accessory`スロットを1枠新設。ジョブを問わず装備可能。
- **オーラの結晶**：武器熟練技「極撃」・胴防具熟練技「再生」の発動率を各15%→45%（3倍）。威力は変わりません。
- レーヴァテインと玄武の鎧の両方を所持する従来の開発用セーブへ、一度だけ付与・自動装備。新規セーブには配布しません。
- アカウント認証がないため、所有者本人を識別して配布する仕組みではありません。既存の特別装備を所持しているかで判定します。

### ジョブ制限

- 装備そのものにジョブ制限はありません。転職時も装備、6能力値、HPを維持。
- ショップの品揃えはジョブ別。カジノ景品の交換時ジョブ制限を解除しました。
- 今後構想している一部職業専用装備は未実装です。
