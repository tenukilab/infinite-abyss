# 無限迷宮アビス — v0.5（6能力値システム）

チャット上のオリジナルハクスラをブラウザゲームとして試作中。画像・外部ライブラリなし。`index.html` ひとつで実行できます。GitHub Pages で配信します。

## v0.5 主な変更

- **旧セーブを初期化**：旧キー `infinite-abyss-save-v1` ～ `v4` をページ起動時にローカルから削除。新キーは `infinite-abyss-save-v5`。以前のJSONは読み込み不可。すでに他端末に保存されているデータは、その端末で新しいページを開くまで残ります。
- **6能力値制**：力、魔力、生命力、器用さ、素早さ、運。旧ATK・DEF・会心率・会心時回復・被ダメ軽減率などのキャラ能力値は廃止。HPは戦闘リソースとして継続（生命力などから算出）。MPなし。
- **4職業**：ファイター／魔術師／ヒーラー／シーフ。総合Lvと現在のジョブLvに同量のEXPを加算、ジョブLvは60が上限。ジョブLvに応じて5/15/30/45/60でスキル解放。
- **商品は各ジョブ5個**：固定の武器1・防具4（頭、胴、手、足）。同じ価格帯、近い能力値で暫定実装。敵は装備を落とさない。ショップの商品の性能は6能力値への補正のみ。
- **スキル**：20種を維持。各スキルが倍率・基礎発動率・任意の追加効果を持つ。戦闘でMP消費なし。上位スキルから抽選し、命中した行動につき最大1スキル。魔術師の魔力暴走は独立したパッシブで維持。

## 6能力値と暫定計算

| 能力 | 役割 |
| --- | --- |
| 力 (`str`) | ファイター・シーフの物理攻撃力 |
| 魔力 (`mag`) | 魔術師・ヒーラーの魔法攻撃力 |
| 生命力 (`vit`) | 最大HPと、総合レベルアップ時のHP増加 |
| 器用さ (`dex`) | 自分の命中率 |
| 素早さ (`agi`) | 敵の命中率を下げる（回避）、行動回数を決める |
| 運 (`luk`) | 命中・回避・スキル発動・魔力暴走・ダメージ揺れ・Gボーナス・鉱石抽選に影響 |

**仮の数式（後で調整可能）**

- 基本能力値：ジョブ基礎値 ＋ `floor((総合Lv - 1) * ジョブ成長係数)` ＋ 装備補正 ＋ 強化補正
- 最大HP：`50 + 生命力 * 4 + 累積HP成長量`。総合レベルアップごとに `4 + floor(その時の生命力 / 2)` を累積HP成長量へ追加
- 物理・魔法ダメージ：基本は該当能力値 `×2.05 + 2` をベースに、少量の乱数とスキル倍率を適用
- 命中率：`clamp(82 + 0.65*(攻撃側の器用さ - 防御側の素早さ) + 0.23*(攻撃側の運 - 防御側の運), 52, 98)%`
- 回避：相手からの命中判定に失敗したら回避
- 行動回数：`1 + min(3, floor(素早さ / 20))`（最大4回/ターン）
- スキル抽選率：`clamp(基礎発動率 + 運 × 0.18, 0, 85)%`（各スキル抽選の判定成功率。使用割合そのものではない）
- 魔術師の魔力暴走率：`clamp(10 + 運 × 0.15, 10, 45)%`、ダメージ2.5倍
- 第3層以降の鉱石抽選は運により上昇。装備ドロップは引き続きゼロ

## 遊び方

1. `index.html` を開く。新規Lv.1魔術師、100Gでスタート。
2. 拠点で武器・防具を購入。ジョブ別に固定5商品が並ぶ。
3. 探索で1 / 5 / 10 / 20 / 30戦を自動周回。安全撤退HPを指定できる。
4. ジョブ画面で転職・スキル習得状況を確認。
5. 記録画面でセーブJSONを出力・読込、データ初期化。

## セーブ上の注意

保存先はブラウザの `localStorage`。サーバー・DBは使用しません。旧版のセーブデータは新しいページを読み込むと削除されます。v0.5のJSONだけインポートできます。バックアップを取る場合は記録画面で出力してください。

## 実装メモ

- 装備レアリティ・旧ドロップテーブルは撤去。鉱石素材と鍛冶屋は試作として残置。
- 職業別成長率、敵の能力値、命中率・回避率・行動回数の閾値、スキル確率はすべて**仮設定**。今後の調整を前提にコードに集約。
- 現行バージョンは個人用オフライン試作。App Store 審査・課金・アカウント機能には未対応。
