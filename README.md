# 無限迷宮アビス v0.15 — 自動周回（Phase 1）

iPhoneのSafariとPCブラウザで動く、オフライン・シングルHTMLのブラウザRPGです。ソースは `index.html` のみで実行できます。

- 公開版： https://tenukilab.github.io/infinite-abyss/
- GitHub： https://github.com/tenukilab/infinite-abyss
- セーブはブラウザの `localStorage` に保存。JSON書き出し・取り込みに対応。
- **v0.14までの既存セーブは初期化されません。** 6能力値、6下級ジョブ、ジョブマスター、装備・熟練度・アクセサリー・魔法、魔の森・カジノの進行・戦闘記録を継続します。

## v0.15：自動周回

通常迷宮の探索画面と魔の森に「自動周回」パネルを追加しました。

### 標準設定

| 項目 | 標準値 | 備考 |
|---|---|---|
| 最大周回数 | **1,000戦** | 1～1,000戦の整数を入力可能 |
| 撤退HP | **最大HPの30%以下** | 0～100%の整数を入力可能。戦闘前後に判定 |
| ジョブマスター到達停止 | **有効** | 現在のジョブがLv.60になると、その戦闘終了後に停止。既にLv.60なら開始不可 |
| 敗北停止 | **有効（固定）** | 敗北後に元の階層を自動周回し続ける事故を防止 |
| ボス再戦許可 | **有効** | 魔の森の10階ごとのボスで繰り返し挑戦。禁止時はボス階で開始不可 |

通常迷宮のボスは既存仕様で再戦不可のため、倒した時点で停止します。

### 処理と安全性

- **既存の `fightOne` 戦闘エンジンを1戦ずつ実行**。魔法の使用回数、スキル、ウォール、極撃・再生、熟練度の成長、敵の特殊行動、レベルアップ、G・EXP・鉱石等に従来どおりの処理を適用。
- 戦闘をまとめて一括シミュレーションせず、戦闘の間にタイマーでブラウザに制御を返します。iPhoneでも途中停止が可能です。
- **毎戦ごとにセーブを保存**。画面表示更新は約5戦ごとに間引き、負荷を軽減。
- 「停止」を押すと次の戦闘を始めず終了。実行中は他の操作（転職、装備変更、階層変更、宿屋等）をブロック。
- 自動宿屋・自動転職・自動階層移動は未実装。最初に選んだ階層とジョブ・装備で戦い続けます。
- 魔の森の直近**30戦分**はターンごとの詳細戦闘記録をセーブに保存。すべての1,000戦分を保存するわけではありません。
- 周回終了理由・累計戦闘数・EXP・G・熟練EXPを「記録」と周回パネルに表示。途中の報酬も永続化。
- **画面を閉じたりSafariが非表示になったら停止**。ブラウザの制限による中断時も、再読み込みで自動再開せず、保存済みの成果だけを引き継ぎます。オフライン時間分の周回加算はしません。

### 注意点

- 「撤退HP30%」は、**敗北を防ぐ保証ではありません**。戦闘途中にHPがゼロになった場合は敗北して停止します。
- セーブは端末・ブラウザごと。別の端末からの自動周回や、サーバーを使ったオフライン周回には対応していません。
- 1,000戦を実行する時間は敵・育成状態・ブラウザ性能によって異なります。極端に長い戦闘では1回の戦闘計算に時間がかかることがあります。

## v0.14以前の既存機能

下級6職（戦士、魔術師、ヒーラー、シーフ、弓使い、ナイト）、各5種のスキル、ジョブマスター・2つ目のパッシブ、転職時の永久6能力値維持、武器・胴防具の熟練技、魔法店・魔法器・ウォール、装備基本攻防、オーラの結晶、カジノ島、魔の森50階・ボス、魔の森の戦闘詳細ログなどを引き続き使用できます。
