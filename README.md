# 無限迷宮アビス v0.18 — 異世界の自動周回

## v0.18：異世界の自動周回

- 異世界の画面に**自動周回**を追加。最大1,000戦、戦闘ごとに通常25体のボスから抽選（ぴーるなだけ0.01%の特別抽選）。既存の戦闘処理をそのまま使用。
- **150ターン時間切れ撤退は自動周回の即停止条件**。獲得EXPは敵設定の70%、Gは0。通常の敗北ではなく、死亡数・所持Gの損失なし。
- HPが最大HPの30%以下、敗北、現ジョブMASTER到達、指定戦闘数完了、手動停止でも終了。ボス再戦許可はONで開始する（異世界はボス戦のみ）。
- 「**ぴーるな遭遇時に停止**」を標準ONに設定。出現した時点で戦闘前に停止し、相手のIDをセーブへ保存。手動挑戦や拠点への帰還・再読み込みを経ても、次の異世界戦闘でその相手と戦える。OFFならそのまま自動戦闘可能。
- 勝利時の魔法ドロップ**1%**は従来どおり。周回画面に累計ドロップ数を表示し、前回の自動周回に獲得魔法の内訳を記録。異世界の直近30戦について150ターンまでの詳細ログを保持。
- 1戦ごとに成果・戦績・ドロップ・熟練度を保存。iPhoneで画面を閉じた場合は停止し、ブラウザ再起動時に自動再開しない。自動宿屋・自動転職・オフライン周回は未実装。
- セーブキーを変更せず旧データを維持。過去の職業・装備・魔法・カジノ・魔の森の進行は引き継ぐ。

### テスト

- iPhone幅ブラウザで8戦の通常周回と、テスト用に猫出現を無効化した1,000戦完走（魔法・EXP・G・直近30戦を確認）
- ぴーるな遭遇で戦闘前停止・リロード後も遭遇保持・手動戦闘での消費
- テスト用確率固定で150ターン撤退即停止・EXP70%・G0、魔法ドロップの件数集計
- 手動停止・画面非表示による停止・すでにMASTERの場合の停止条件・旧セーブ互換性

## v0.17 — 異世界・ぴーるな・150ターン制限

## 異世界（新規）
- 拠点から入場できる、階層なし・1戦につきランダムボス1体のダンジョン。
- 通常ボス25体には、毒・出血・麻痺・暗闇・回復封じ・魔法封印・防御破壊・ウォール破壊・高倍率攻撃など、それぞれ異なる特殊行動を設定。
- 勝利した戦闘ごとに**1%**で魔法1個を獲得。ファイアー・ヒール・ビール・ウォールを現在は均等に抽選（当選後、各25%）。魔法は残り3,000回。将来のドロップ用レアリティ項目 `dropRarity` を準備済み。
- 「異世界の戦闘記録」には直近30戦のターン別処理を保存。自動周回はまだ未対応。

## 超低確率の猫「異世界に迷い込んだぴーるな」
- 異世界挑戦時に**0.01%**の特別抽選で出現。非出現時は通常25体から均等抽選。
- HP1。攻撃の命中率は常に**0.001%**（職業・運・魔法の命中補正によらず固定）。ファイアーにも同じ判定。
- 毎ターン、ゴロゴロ・おててないない・ふみふみなどの猫らしい行動を記録。**0.05%／ターン**で「ねこパンチ」を使い、必中即死。ウォール・防御を無視。
- 撃破報酬は**30,200,000 EXP／7,400,000 G**。通常異世界ボスの平均報酬約100戦分。
- 時間切れで倒せなければ、共通撤退ルールで**21,140,000 EXP／0 G**。

## 全戦闘150ターン制限
- 通常迷宮・魔の森・異世界に適用。
- 倒せないまま150ターン到達：**撤退**として、その敵のEXP70%とG0を獲得。死亡・所持金減少はなし。HP0による敗北は従来どおり。
- v0.16のジョブ・装備・魔法・自動周回・セーブを維持。

## テスト
- JavaScript構文・スマホ幅ブラウザ表示・セーブ移行
- 15万回の異世界出現抽選（猫14回、通常25体すべて出現）
- 確率固定テストで、猫の150ターン撤退、必中ねこパンチ、命中時の高額報酬
- 魔法ドロップの取得と魔法管理への反映、通常ボスの状態異常・戦闘記録

# 無限迷宮アビス v0.16 — 上級職7職を追加

オフライン・シングルHTMLのブラウザRPG。iPhone Safariを想定した操作UI。セーブはブラウザの `localStorage` に保存されます。

[プレイ](https://tenukilab.github.io/infinite-abyss/)

## 変更点

- 下級職「魔術師」を**魔法使い**へ表示名のみ変更。既存の内部ID `mage`、ジョブLv、習得スキル、経験値、マスター記録はすべて維持。
- 上級職を7職追加。**新規にそれぞれLv.1から育成**し、ジョブLv.60でマスター。既存の6下級職と合わせて13職。
- 転職時の6能力値・最大HP・現在HP・装備・熟練度は変更しない。総合Lvは共通。
- 上級職の転職条件を実装。職業画面で未達条件を表示し、未達なら転職ボタン無効。解放条件は各下級職のマスター（Lv.60）。

| --- | --- |
| 重騎士 | ナイト |
| フェンサー | 戦士 |

## 新しい職業の暫定戦闘スタイル

上級7職は通常パッシブとLv.60マスターパッシブを追加。すべて仮数値で、今後の調整対象。

| 上級職 | 通常パッシブ | マスターパッシブ（その職に就いているときだけ） |
| --- | --- | --- |
| 重騎士 | 被ダメ20%軽減 | HP半分以下でさらに35%軽減 |
| フェンサー | 命中+5ポイント | 与ダメージ×1.2 |
| 魔術師 | 魔力暴走2.5倍 | 暴走4倍 |
| クレリック | 毎ターン最大HP3%回復 | 回復量が8%に強化 |
| アーチャー | 命中+15ポイント | 命中時30%で最終ダメージ×2.5 |
| 曲芸師 | 攻撃回数+1 | 与ダメージ×1.2 |
| バンデット | 勝利時G+20% | ボーナスが+40%に強化 |

各上級職にジョブLv.5/15/30/45/60で習得する5スキル（計35スキル）を暫定実装。既存スキルと同じ自動発動方式。上級職用のショップ商品も各5種類追加。装備自体に職業制限はなし。カジノ景品の追加は今回なし。

## セーブ互換性

- 保存キー `infinite-abyss-save-v5` と `VERSION=5` を維持し、上級職の不足する育成データ（`jobProgress` / `loadouts`）を起動時に追加。
- 下級職はすべて従来の内部IDのまま。魔法使いは `mage`、上級魔術師は新規 `sorcerer` で混同なし。弓使いは `archer`、上級アーチャーは `elite_archer`。
- 既存の装備・6能力値・魔法・オーラの結晶・ウォール・カジノ・魔の森50階・戦闘詳細・自動周回履歴を引き継ぐ。
- ジョブ変更中に装備や能力値を再計算しない。上級職でもレベルアップ時の能力値加算のみ行う。
