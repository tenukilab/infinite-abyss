# 無限迷宮アビス v0.9 — 魔の森（50階層）

チャットで仕様を追加しながら制作する、オフライン・シングルHTMLのハクスラRPG。

## プレイ

- GitHub Pages: https://tenukilab.github.io/infinite-abyss/
- `index.html` 単体で動作。セーブは端末ブラウザの `localStorage` に保存。記録画面からJSON形式でバックアップ可能。
- **v0.8のセーブを引き継ぎます。** 装備・熟練度・魔法・カジノ・通常迷宮の進行を初期化しません。

## v0.9：魔の森

- 拠点に **「魔の森への道」** を新設。通常迷宮と独立して **1〜50階** を探索します。拠点へ戻るときも進行は保持されます。
- **通常階：3勝で次階を解放**（仮設定）。通常階で1/5/10/20/30連戦が可能。
- **10・20・30・40・50階：ボス戦専用。** 倒すと次階を解放し、討伐後もボスと再戦可能。最終50階は討伐フラグを保持し、それ以上の階はありません。
- 50階ボスは他階から急激に難易度が跳ねる仮バランス：ボスHP **12,000,000**。40階ボスのHP **270,000** に対して約44倍。攻撃性能も大幅に上げています。
- 魔の森でも共通キャラクターの総合Lv/ジョブLv、HP、所持G、装備熟練、魔法使用回数を使います。魔の森の進行は `state.forest`（`floor`、`unlocked`、`kills`、`bossesDefeated`）で独立保存。
- 敗北時は従来のGペナルティとHP復帰を適用し、魔の森の入口（1階）へ戻ります。解放済み階層は保持されます。
- 戦闘ではEXPとGを獲得します。通常迷宮の進行や `state.kills` は変わりません。

### アイテム／素材・魔法ドロップの拡張口（**未実装**）

- 将来の素材・武具合成用 `ITEM_CATALOG` を**空の定義**として作成。素材アイテムの配布・収集・武具合成はまだありません。
- `FOREST_BOSS_DROP_TABLES` にボスごとに `{items:[], magics:[]}` の**空テーブル**を5件定義しました。
- **現在の森のボスからは素材も魔法もドロップしません。** 実際の抽選や追加魔法・素材の中身は後から設計・実装します。
- 従来の通常迷宮の装備ドロップ廃止や、カジノ景品「錆びた始原剣」の保管方式は変更しません。

## 継続する既存機能

- 4職（ファイター／魔術師／ヒーラー／シーフ）、総合LvとジョブLv、6能力値、職業別成長、スキルと魔力暴走。
- 5階層の通常迷宮。ジョブ別固定5商品の武器屋・防具屋、宿屋・鍛冶屋。
- 武器・胴防具の個別熟練度（50EXPで熟練+1、一般の上限2000、熟練技15%、500熟練で技効果上限）。
- 回数制魔法（上限5000回）、魔法店（店回復上限3000回、残り799以下は店で回復・合成不可）、魔法石・太陽石、1ターン最大1魔法。
- カジノ島（ポーカー／ルーレット／競馬、メダル交換、景品交換）。
