# 無限迷宮アビス v0.14 — 下級職6種類とマスターパッシブ

スマホブラウザ対応のオフラインRPGです。`index.html`を開くだけで遊べます。

- プレイ： https://tenukilab.github.io/infinite-abyss/
- セーブ：端末ブラウザの`localStorage`。記録画面からJSONエクスポート／インポート可能
- **v0.13の既存セーブは維持**。育成済みの能力値・職業Lv・装備・熟練度・魔法・カジノ／魔の森の進行・戦闘記録に変更なし

## v0.14で追加・変更した内容

### 下級職が4→6職に

| 内部キー | 表示名 | 成長の方向 | 通常パッシブ |
|---|---|---|---|
| `fighter` | **戦士**（旧ファイター） | 力・生命力 | 既存の通常パッシブは未設定 |
| `mage` | 魔術師 | 魔力 | 魔力暴走（従来どおり） |
| `healer` | ヒーラー | 魔力・生命力 | 既存の通常パッシブは未設定 |
| `thief` | シーフ | 力・器用さ・素早さ | 既存の通常パッシブは未設定 |
| `archer` | **弓使い** | 器用さ・力・素早さ | **照準**：命中率+10ポイント（最大99%） |
| `knight` | **ナイト** | 生命力・力 | **守護**：敵からの被ダメージ10%軽減 |

- 下級職の転職条件は全員なし。
- 転職しても**永久成長した6能力値・最大HP・現在HP・装備は変化しません**。総合Lvのレベルアップ時だけ、その時のジョブに応じて能力値が増加します。
- 既存セーブへの新職業追加時は、弓使い／ナイトのみジョブLv1・EXP0から開始。内部キー `fighter` は維持して旧データとの互換性を確保。
- 各職5商品で、**6職×5商品＝30商品**。ショップのラインナップは現職に依存しますが、**実際の装備に職業制限はありません**。
- 各職5つのアクティブスキル（ジョブLv 5/15/30/45/60）。弓使いとナイトにも各5つ追加。スキルは従来どおり自動発動、MPなし。
- カジノの職別高性能武器に「流星の長弓」「守護者の聖槍」を追加（各2,000メダル）。

### ジョブLv60の「マスター専用第2パッシブ」を実際に適用

| ジョブ | マスターパッシブ | 効果 |
|---|---|---|
| 戦士 | 不屈の闘志 | 現在HPが最大HPの50%以下なら**最終与ダメージ×1.25** |
| 魔術師 | 魔力の極致 | 魔力暴走のダメージ倍率が**2.5倍→3.5倍** |
| ヒーラー | 生命の泉 | **毎ターン開始時**に最大HPの5%を回復（端数切り上げ） |
| シーフ | 神速 | 1ターンの行動回数**+1**、通常最大4回を超えて最大5回 |
| 弓使い | 弱点看破 | 命中時、約25%で**最終与ダメージ×2**（運による微補正あり） |
| ナイト | 不落の構え | 現在HPが最大HPの50%以下なら、敵の被ダメージ**さらに30%軽減** |

- **マスターパッシブは該当職業で戦っている間だけ有効**。他職に転職しても「MASTER」資格は失いませんが、特典は持ち越しません。
- ナイトの常時被ダメ−10%と、マスター時HP半分以下の追加−30%は乗算で重なります。壁のダメージ吸収より先に適用。
- 戦士の与ダメ+25%と弓使いの弱点看破は、熟練技・魔法「ビール」などを反映した最終攻撃ダメージへ乗算。
- `jobRequirements`（将来の上級職で必要なマスター職を指定できる構造）は継続。上級職・グランドマスターは未実装。

### これまでの機能を維持

- レーヴァテイン（基本攻撃12,000＋熟練2,000×5で22,000）、玄武の鎧（基本防御2,500＋熟練2,000で4,500）、オーラの結晶、装備固有の熟練技
- 魔法店・魔法石・太陽石、ファイアー・ヒール・ビール・ドロップ専用予定のウォール
- カジノ島、通常迷宮、魔の森50階、ボス暴走／50階ボスの麻痺・壊撃、戦闘のターン別記録
- 開発用特別装備・ウォールの配布判定は変更なし。新規セーブには配布されません
