# 無限迷宮アビス v0.3 — 4職業・ジョブレベル制

会話から生まれた、画像・外部ライブラリなしのオフラインブラウザRPG。公開版: https://tenukilab.github.io/infinite-abyss/

## v0.3 の主な変更

- **4職**: ファイター、魔術師、ヒーラー、シーフ。画面の「ジョブ」タブから転職できる。転職後は第1層に戻り、HP割合を維持。
- **総合LvとジョブLvを分離**: 戦闘でEXP10を得たら、総合EXPにも現在のジョブEXPにも10を加算。分割・消費なし。
- **ジョブLv60が上限**: Lv60に達するとそのジョブへの以後のEXPは切り捨てる。総合EXPは通常どおり獲得・成長し続ける。
- **転職履歴を保持**: ジョブごとにLv/EXPと装備セットを独立保存。総合Lv、所持G、所持品、階層解放は全職共通。
- **ジョブ別の固定ラインナップ**: 武器屋・防具屋とも現在のジョブに応じて切り替わる。魔術師の旧v0.2商品43点は名前・価格・性能を一切変更していない。ほか3職にも同数の固定商品がある（計172点）。店の商品は抽選で変わらない。**購入条件にジョブLvと解放階層を利用**。
- **装備ドロップ廃止を継続**: 戦闘報酬はEXP・G・第3層以降の鉱石。店で装備購入・鍛冶屋で強化。
- **既存セーブを自動移行**: v0.1/v0.2のセーブキー `infinite-abyss-save-v1` を維持。旧Lv.9魔術師は魔術師ジョブLv.9 / ジョブEXP155として引き継ぎ、既存の装備は魔術師用として保持。旧JSONファイルも読み込み可能。

## 職業の仮パラメータ

| ジョブ | Lv.1時HP | ATK | DEF | 固有特性 |
|---|---:|---:|---:|---|
| ファイター | 140 | 13 | 6 | 受けるダメージを10%軽減 |
| 魔術師 | 85 | 21 | 2 | 会心攻撃10%（旧「魔力暴走」） |
| ヒーラー | 115 | 15 | 4 | 攻撃時HPを3回復 |
| シーフ | 105 | 16 | 3 | 会心率10% |

- ファイター・ヒーラー・シーフの基礎値、名称、特殊効果、商品バランスは**アビス独自の暫定仕様**。
- 総合LvによるHP+10/ATK+2の成長は従来どおり。ジョブLvはショップ購入条件とジョブ育成の進捗管理に使用。今後、ジョブスキル解放等の設計余地あり。
- 経験値テーブルは総合LvとジョブLvで現状共通。ジョブLv60以降に獲得した分を別職に繰り越すことはない。
- アクティブなジョブ専用の装備だけを装着できる。ジョブ別ロードアウトを記憶する。旧装備は削除しない。

## 基本操作

1. **探索**: 階層を選択して1/5/10/20/30戦のオート戦闘。HP撤退条件を設定。
2. **ジョブ**: 職業を切り替え、ジョブごとのLv/EXPを確認。
3. **拠点**: 武器屋・防具屋（ジョブ別固定品）、宿屋20G、鍛冶屋で装備強化。
4. **装備**: 現在のジョブの所持装備を交換・売却。
5. **記録**: 自動セーブ、JSONエクスポート/インポート。

初回状態はチャットログの続き、総合Lv.9・魔術師ジョブLv.9・HP167/196・第3層・908G。新規開始は「記録 → 最初から」。

## 技術・注意事項

- HTML/CSS/JavaScript単一ファイル、GitHub Pages、`localStorage`、決定論的疑似乱数。
- セーブ内部形式は `version:2`。`version:1` の旧セーブは初回読込時に移行。自動更新前にJSONでバックアップを推奨。
- オンライン同期や不正防止サーバー処理はまだない。
- えりいく改のソースコードや名前付きコンテンツのコピーではなく、独立したハクスラとして実装。
