# 無限迷宮アビス v0.11 — 転職時の能力値・装備維持

チャットで仕様を追加しながら制作する、オフライン・シングルHTMLのハクスラRPG。

## プレイ

- GitHub Pages: https://tenukilab.github.io/infinite-abyss/
- `index.html` 単体で動作します。セーブはブラウザの `localStorage`、JSON書き出し・読み込みも利用可能です。
- **既存のv0.10セーブは引き継ぎます。** 装備・熟練・魔法・カジノ・魔の森の進行は初期化しません。

## v0.11：転職時の挙動修正

- **転職時は力・魔力・生命力・器用さ・素早さ・運、最大HP・現在HPを変更しません。** レベルアップの際だけ、その時点のジョブに合わせて6能力値が永久に加算されます。
- 原因は転職時にジョブ専用の装備セットへ自動変更される挙動でした。これを廃止し、**現在の装備は転職後も維持**する方式に変更しました。
- 装備はどのジョブでも装備できるようにし、武器屋・防具屋の品揃えは引き続きジョブ別です。購入した装備は共通の所持品に残り、装備変更は明示的な操作時のみ発生します。
- 武器強化の補正先は**武器の由来となるジョブ**を参照。装備したまま転職しても力・魔力の補正先が変わりません。汎用武器は元の武器性能に基づいて補正先を決めます。
- セーブ互換性のため既存の`loadouts`フィールドは保持しますが、すべて同じ現在装備へ同期します。旧ジョブ別装備セットは自動切り替えされません（所持アイテムは消えません）。
- 転職後に変更されるのはジョブ名・攻撃種別・ジョブスキル・パッシブ、および従来どおり通常迷宮の選択階層（1階層目へ）です。

## v0.10：魔の森のターン別バトルログ

- 魔の森の各戦闘ごとに **「記録」** ボタンを追加。タップすると戦闘の**全ターン**を展開できます。
- 各ターンに味方HP・敵HPの「開始→終了」と、行動順のイベントを記録します。魔法、命中失敗、ジョブスキル、魔力暴走、武器熟練技、回復、敵の反撃、回避、防具熟練技などを表示します。
- **連戦でも1戦ごと**に記録します。通常階と10階ごとのボスの両方に対応。敗北も記録します。
- 魔の森の直近**30戦分**の詳細を `state.forest.battleRecords` に保存し、ブラウザを再読み込みした後も閲覧できます。31戦目以降は古い順に削除します。
- 長期戦でも20イベントで打ち切らず、最大120ターン分を保持します。表示はボタンを押した戦闘だけ展開し、スマホの画面負荷を抑えています。
- **v0.10導入以前に行った戦闘の詳細ログは復元できません。** 既存のテキスト履歴は以前どおり保持します。
- 戦闘計算・報酬・確率・バランスそのものは変更していません。通常迷宮のログ表示も従来どおりです。

## 既存仕様（継続）

- 魔の森は通常迷宮と進行が独立した50階層。通常階は3勝で解放、10・20・30・40・50階はボス専用。ボスは再戦可能。
- 魔の森の素材・魔法ドロップテーブルはボスごとに用意済みですが、現在は空でドロップはありません。
- 4職（ファイター／魔術師／ヒーラー／シーフ）、総合LvとジョブLv、6能力値、職業別成長、5段階スキルと魔力暴走。
- 5階層の通常迷宮、武器屋・防具屋、宿屋・鍛冶屋。武器・胴防具には個別熟練度と熟練技。
- 最大5000回の回数制魔法、魔法店（回復上限3000回・799以下は店で回復／合成不可）、魔法石／太陽石。
- カジノ島（ポーカー／ルーレット／競馬）と景品交換。
