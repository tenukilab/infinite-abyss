# 無限迷宮アビス — v0.2（装備ショップ方式）

チャット上で始めた「無限迷宮アビス」の単一HTMLブラウザゲーム。2026-11の仕様変更により、**新規戦闘での装備ドロップを廃止**し、装備は武器屋・防具屋で購入する方式に変更しました。画像・外部ライブラリ・バックエンドなし。

## 遊び方

1. `index.html` をスマホやPCのブラウザで開く（公開版： https://tenukilab.github.io/infinite-abyss/ ）。
2. **探索**：階層を選んで1/5/10/20/30戦のオート戦闘を実行。HP撤退条件を設定可能。
3. **戦闘報酬**：経験値・G（3層以降は鉱石も）。**装備は一切ドロップしない**。
4. **拠点 → 武器屋**：杖を購入。**拠点 → 防具屋**：頭・胴・手・腰・足・首飾り・指輪を購入。購入すると即装備し、旧装備は所持品に残る。
5. **拠点 → 宿屋・鍛冶屋**：宿屋20Gで全回復、鍛冶屋で強化。
6. **装備**：旧装備の再装着・不要な装備の売却が可能。
7. **記録**：プレイ履歴とJSONセーブデータのエクスポート・インポート。

初回は**チャットログの終了地点**（Lv.9／第3層／HP167/196／EXP155/265／908G／ATK53／DEF11／魔力暴走率15%）から再開。記録タブの「最初から」でLv.1からプレイ可能。

## ショップ仕様（v0.2の仮ルール）

- **固定ラインナップ・固定価格・固定性能**。店の在庫抽選や品切れはまだ導入しない。
- 階層を解放すると、その階層に対応する商品が入荷。商品ごとに必要レベルあり。
- 購入した商品は自動装備。装備中の商品を上書きしても旧装備は消えない。
- 同一の商品は所持中に重複購入できない。売却すれば再購入できる。
- 店で購入した装備を売却すると、購入価格の35%（切り捨て）を獲得。強化費用の一部は追加売却額に反映される。
- 既存のドロップ装備は削除せず、そのまま装備・保管・売却可能。過去のチャットログの履歴も変更しない。
- 2つの店以外から新しい装備を生成しない。第5層ボスも装備はドロップしない。

装備厳選や確率要素は一旦ショップ導入を優先して停止しました。今後の設計によって、ランダム在庫やクラフト・能力付与などの形で追加できます。

## 技術とセーブ互換性

- 純粋なHTML/CSS/JavaScript、外部通信・パッケージなし
- xorshift32疑似乱数（戦闘用）
- `localStorage` 自動保存・JSON入出力
- **旧v0.1のセーブキー `infinite-abyss-save-v1` とデータ形式を維持**して互換性を確保。新規購入品は任意フィールド `shopSku` を持つだけで、既存セーブはそのまま読み込める。
- 別ブラウザ・別端末とのセーブ同期はなし。ブラウザのデータ消去に備えてJSONバックアップを推奨。

## ログ再現の限界と更新履歴

v0.1ではチャットで獲得した装備と確定ステータスを保持して開始し、追加戦闘・ドロップは新しいPRNGで処理していました。過去47戦の個別乱数列は保存されていないため、過去の抽選を再現しているわけではありません。

v0.2ではユーザーの仕様変更に基づき、以後の**装備ドロップを完全廃止**。武器屋・防具屋の品揃え、価格、入荷条件は現時点で新しく補完した仮仕様です。将来のバランス調整対象としています。
