# 無限迷宮アビス v0.7 — 武器・胴防具の熟練度


チャットから生まれたオリジナルのオフラインブラウザゲーム。HTML/CSS/JavaScriptの1ファイル（`index.html`）で動作。GitHub Pagesで公開。

## v0.6 新機能

- **ジョブ別の永久成長**：総合Lvが上がった瞬間のジョブに応じて6能力値が加算される。転職後もそれまでの能力値は失われない。各ジョブの成長値は `levelGrowth` テーブルで設定。整数部分は確定、端数部分は確率判定。
- **カジノ島**：拠点内の船便から移動。カジノ島では通常の探索メニューを切り替え、専用画面を表示。帰還すると拠点に戻る。
- **ゴールド→メダル**：10G = 1メダル。1/10/50/100メダル単位で交換可能。メダル→Gの逆交換は未実装。
- **ドローポーカー**：5枚を配り、ホールド指定したカード以外を一度交換。ポーカー役を判定して払い戻し倍率を適用。ポーカー進行状況もセーブされ、再読み込みで二重払い戻しにならない。
- **ルーレット**：0〜36のヨーロピアン方式。赤・黒・偶数・奇数は配当2倍、数字一点は36倍。0は赤黒・偶奇の敗北。
- **島の競馬**：4頭から単勝を選択。勝率は40%、30%、20%、10%を基本として、配当は2/3/5/9倍。
- **景品交換所**：各ジョブ専用の高性能武器を1本ずつ（各2000メダル）、将来の武器合成に使用する「錆びた始原剣」（500メダル）。景品は一度きりの交換で、カジノ武器は売却不可。錆びた始原剣は装備不可の保管素材。**武器合成機能と素材収集は未実装。**

## レベル成長の設計

6能力値は「力・魔力・生命力・器用さ・素早さ・運」。HPは生命力などから計算。職業によってレベルアップ時に伸びやすい能力が異なる。

| ジョブ | 成長の特徴 | 例（確定成長） |
| --- | --- | --- |
| ファイター | 力・生命力 | 力+2、生命力+1 |
| 魔術師 | 魔力 | 魔力+2 |
| ヒーラー | 魔力・生命力 | 魔力+1、生命力+1 |
| シーフ | 力・器用さ・素早さ | 各+1 |

副次的な能力値には確率成長がある。ジョブLv60の上限・総合EXPとジョブEXPへの同量加算・ジョブLv5/15/30/45/60のスキル習得・4職合計20スキルは維持。

全ジョブマスター後の**グランドマスター**および上級職は構想段階であり、v0.6には未実装。今後の設計を前提とする。

## カジノの仕様・制約

- すべて**ゲーム内で獲得したゴールドとメダルのみ**。現金・暗号資産・有料購入・外部交換・払い戻し等は一切なし。オンラインのランキングや運営サーバーもなし。
- 1回のベットは1〜500メダル。払い戻し倍率は**元の賭け金を含む**。負ければベット分が減る。
- キャラの「運」は、抽選後の小さな救済判定としてポーカー・ルーレット・競馬にもわずかに影響する。**これらのゲーム内確率は現実のゲームと一致しない**（すべて仮バランス）。
- カジノ通貨・購入済み景品・進行中のポーカー手札はブラウザ `localStorage` に保存。
- JSONセーブの書き出し・読み込みは可能。オフラインゲームのため、セーブデータの改造や巻き戻しによる不正防止は行わない。将来オンライン化する場合はサーバー側で通貨・抽選・景品購入を管理する必要がある。

## v0.5 からの移行

保存キーは引き続き `infinite-abyss-save-v5`。**v0.5のデータは消去しない**。

旧セーブには無かった `baseStats`、`medals`、`casino`、`location` を読込時に補完する。すでに獲得したレベルは、移行時点のジョブにおけるv0.5の能力値に換算し、以後はジョブ別の永久加算に切り替える。従来の履歴、ジョブ進行、装備などは維持。v0.5のJSONセーブも取り込み可能。

## v0.7：武具熟練度（試作）

- 対象は武器と胴防具。頭、手、足にはまだ熟練経験値を付与しない。
- 戦闘が終了するたび、装備していた武器と胴防具にそれぞれ乱数で **熟練EXP 1〜4** を付与。勝利・敗北両方を対象にする。
- 必要EXPは全レベル共通で **50**。装備品が変わってもその品の熟練度は維持され、別の品には移らない。
- 通常装備の熟練度上限は **2000**。`maxMastery` は個別の装備品に保持するため、将来3000などの例外を設定できる。
- 熟練50で熟練技解放、以後50ごとに威力・回復量が成長。**熟練500で効果は上限**。熟練度自体は2000まで育成できる。
- 武器「極撃」：**命中ごとに15%**、最終攻撃ダメージに倍率を掛ける。熟練50→×5、100→×10、…500以上→×50。ジョブスキル・魔力暴走と重ね掛け可能。
- 胴防具「再生」：**被弾ごとに15%**、生存していれば最大HPに対する割合回復。熟練50→10%、100→20%、…500以上→100%。HP0後の蘇生はしない。
- 熟練技発動率は固定 **15%**（運による補正なし）。熟練EXPの獲得乱数も現段階では運補正なし。
- ユーザー開発環境へのテスト配布：v0.6の**既存のブラウザセーブ**がv0.7へ初回移行される場合に限り、**レーヴァテイン**（武器）と**玄武の鎧**（胴防具）を熟練2000で1回だけ配布し、現在ジョブへ装備する。職業共通の特殊装備として扱う。新規スタートには配布しない。アカウント識別がないため、同じ版の既存セーブを持つ別ブラウザでも配布される点に注意。
- 既存セーブはクリアしない。JSONエクスポートも継続。
