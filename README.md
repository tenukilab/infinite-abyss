# 無限迷宮アビス v0.6 — カジノ島・永久成長システム

チャットで始まったオリジナルのオフライン・ハクスラRPG。単体の `index.html` （HTML/CSS/JavaScript）で動作し、GitHub Pagesで配信します。

## v0.6で追加した内容

- **永久成長方式**：レベルアップの瞬間に就いているジョブに応じ、6能力値を加算。転職しても一度増えた能力値は維持される。各ジョブの成長値は `levelGrowth` テーブルで設定し、整数部分は確定、端数は確率成長。
- **カジノ島への移動**：拠点の「カジノ島へ渡る」ボタンから移動。島では専用メニューが表示され、帰還で拠点へ戻れる。
- **メダルへの両替**：ゲーム内の10G → 1メダル。1/10/50/100メダル単位で両替。逆換金はできない。
- **ドローポーカー**：5枚を配り、残すカードを選んで一度交換。役に応じて0〜200倍の配当。未完了の手札も保存され、リロード時の二重払い戻しを防ぐ。
- **ルーレット**：0〜36、赤黒・偶奇は2倍、数字一点は36倍。0は赤黒・偶奇では外れ。
- **島の競馬**：4頭の単勝式。基本の勝率40/30/20/10%、配当2/3/5/9倍。
- **景品交換所**：各ジョブ専用の高性能武器（2000メダル）4種類、合成用の「錆びた始原剣」（500メダル）1種類。景品は一度限り入手可能。カジノ武器は売却不可。「錆びた始原剣」は現時点では装備できない合成素材として保管する。

**上級職、グランドマスター、武器合成の実行、最強武器のレシピ・追加素材は未実装**。今後の設計のための土台だけ用意しています。

## 4職業と永久成長

| ジョブ | 確定で伸びる能力値（総合Lv+1あたり） | 補助的な確率成長 |
|---|---|---|
| ファイター | 力+2、生命力+1 | 魔力、器用さ、素早さ、運 |
| 魔術師 | 魔力+2 | 力、生命力、器用さ、素早さ、運 |
| ヒーラー | 魔力+1、生命力+1 | 力、器用さ、素早さ、運 |
| シーフ | 力+1、器用さ+1、素早さ+1 | 魔力、生命力、運 |

総合LvとジョブLvへのEXP同量加算、ジョブLv60上限、スキル習得Lv5/15/30/45/60は維持。魔術師の「魔力暴走」は引き続きパッシブ。各ジョブの店の固定5商品（合計20商品）は変更なし。装備ドロップも廃止したまま。

## カジノの注意点

- ゴールドとメダルは**ゲーム内通貨のみ**。現金での購入や実際のお金への換金、他人への送金・取引はできない。
- ベットは1〜500メダル。配当倍率は元の掛け金を含む。キャラクターの「運」により当選の救済判定がわずかに加わるため、表示するベース確率は実際の最終確率と厳密に一致しない。
- オフラインのため不正防止サーバーはなく、セーブデータの編集や過去データの復元も可能。オンライン化するなら通貨・景品・抽選をサーバー側で管理する必要がある。

## セーブデータ

v0.5と同じローカル保存キー `infinite-abyss-save-v5` を使います。**v0.5のセーブは削除しません**。不足するフィールドを読み込み時に自動補完します。

新しい永久成長能力値 `baseStats` には、移行時点の現在ジョブと総合Lvからv0.5の能力値を設定。移行後のレベルアップは新方式で加算します。既存のレベル・ゴールド・ジョブ育成・装備・戦闘履歴は維持。v0.5のJSONも読み込み可能。カジノの残高、未完了のポーカーの手札、景品の交換状態も自動保存。

## 動かし方

`index.html` をブラウザで開くだけ。オフライン動作。スマートフォン表示に対応。App Store向けのアプリパッケージ化・申請はまだ実施していません。
