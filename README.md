# 無限迷宮アビス v0.4 — ジョブ別スキルシステム

チャットから誕生した、画像・外部ライブラリなしのオフラインブラウザゲーム。**過去の「えりいく改」そのものではなく、クラシックなブラウザRPGに着想を得た独自作品**です。

## 起動・公開

`index.html` だけで動作します。GitHub Pages: https://tenukilab.github.io/infinite-abyss/

セーブはブラウザの `localStorage` （キー `infinite-abyss-save-v1`）で管理します。新しい版でも同じキーを使うことで、旧セーブを継続します。記録タブからJSONバックアップ/復元も可能です。

## v0.4 で追加したスキル

- **ジョブLv 5 / 15 / 30 / 45 / 60** に、それぞれ新しいスキルが解放されます。総合Lvではなく**現在のジョブLv**を参照。
- ファイター、魔術師、ヒーラー、シーフの**4ジョブ×5スキル＝20スキル**を仮実装しました。
- 各スキルの設定値は `index.html` 内 `const skills = {...}` に集約。`level`（解放ジョブLv）、`power`（通常ダメージ倍率）、`rate`（判定発動率、％）、`effect`（追加効果／`null` も可能）を設定。
- **MPも消費回数制限もありません。** 攻撃ごとに自動で抽選します。
- スキルは**高ジョブLvのものから順に、各スキル固有確率で判定**。最初に成功した**1スキルのみ**を使います。従って表示された発動率は「そのスキルが判定対象になったときの成功率」であり、実際の攻撃に占める発動割合ではありません。上位スキルの発動により下位スキルの抽選がスキップされることがあります。
- **魔術師の魔力暴走**（基礎10%・2.5倍）はジョブのパッシブとして残り、アクティブスキルとは**独立して抽選**します。重複すると、スキル威力をさらに2.5倍します。既存の会心・回復装備の処理も維持しています。他ジョブの会心も従来通り。
- 戦闘結果にスキル使用回数・内訳と個々の戦闘ログを表示します。セーブ形式はv0.3から変更なし（`version:2`）。

## 既存の仕様

- 4ジョブに転職可能。総合レベルとジョブレベルは独立し、経験値の獲得時に総合EXPと現ジョブEXPへ**同じ量をそれぞれ加算**。ジョブLv60でジョブEXPだけを切り捨てます。
- 武器屋・防具屋はジョブ別の固定商品。購入すると装着して、旧装備は保管。装備ドロップは**廃止**。
- 迷宮第1〜5層、オート周回（1/5/10/20/30戦）、撤退HP、レベルアップ、鍛冶屋、宿屋など。
- 新規開始またはチャットの最終地点（Lv9・魔術師・第3層・47勝）から継続開始できます。
- 戦闘抽選は保存された擬似乱数状態に基づきます。原チャットの過去47戦の乱数そのものは再現していません。

## 開発時の注意

ゲーム固有データとロジックは現在 `index.html` に同居しています。スキルの調整は `const skills` のみ変更すればよく、ゲーム進行やセーブ構造を変更する必要はありません。iOS化や規模拡張に合わせてデータとロジックを分離する構想です。
