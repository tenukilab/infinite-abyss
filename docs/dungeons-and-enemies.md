# ダンジョン・モンスター台帳（v0.22）

> 状態：[実装済] ダンジョン3系統（通常迷宮50層・魔の森50階・異世界ボス26体）。個別の強さ・特殊行動率は原則[暫定実装]。
> 実装元：`floors` / `FOREST_BOSSES` / `ISEKAI_ROSTER` / `ISEKAI_BOSSES` / `PEELUNA_BOSS`。

## 1. 通常迷宮

**[実装済]** 50層式。既存第1〜5層の必要勝利数：第1層3回／第2層5回／第3層8回／第4層10回／第5層5回。第5層には通常迷宮ボス「腐敗した騎士」が出現。

| 階層 | エリア名 | 解放に必要な勝利 |
| --- | --- | ---: |
| 1 | 湿った回廊 | 3 |
| 2 | 亡者の回廊 | 5 |
| 3 | 灰鉄の坑道 | 8 |
| 4 | 灼熱の鍛造炉 | 10 |
| 5 | 朽ちた王座 | 5（ボス出現条件） |

### v0.22 深層エリア（6〜50層）

第5層ボス「腐敗した騎士」を倒すと第6層解放。第6〜49層は**3勝で次層解放**、第50層が現時点の最深層。旧セーブでボス討伐済みなら読み込み時に第6層が解放される。

**通常モンスター200種**を追加（20種族×10の環境変異、各階4〜5種）。第50層はHP最大約702万、攻撃配列値最大3907、基準EXP約15万、G約3.65万と、異世界の通常ボスより弱い想定の暫定値。特殊行動・素材/魔法ドロップは今回追加しない。

全200体の階層・名前・個別HP・攻撃値・EXP・Gは **[通常迷宮200種のモンスター管理台帳](normal-dungeon-monsters.md)** を参照。

- 通常迷宮の図鑑は従来19種＋新200種＝**219種**。全図鑑は256種。
- 
- ボスの再戦は現状不可。
- 宿屋を使用するとHPを全回復して通常迷宮の第1層に戻る（20G）。

## 2. 魔の森

**[実装済]** 独立した50階ダンジョン。通常階は**3勝で次階解放**。10階ごとにボス戦。倒したボスは再戦可能。

| ボス階 | 名前 | HP | EXP | G |
| --- | --- | ---: | ---: | ---: |
| 10 | 森喰らいの巨鹿 | 5,000 | 750 | 650 |
| 20 | 腐根の女王 | 23,000 | 2,500 | 1,850 |
| 30 | 黒霧の樹竜 | 78,000 | 8,000 | 5,500 |
| 40 | 深緑の魔神 | 270,000 | 23,000 | 13,000 |
| 50 | 魔の森の原初王 | **12,000,000** | 300,000 | 100,000 |

- 全ボス：HPが初めて50%以下になったら**暴走・以後の敵攻撃×1.5**。
- 50階ボス：各ターン20%で**麻痺**（次プレイヤーターン行動不能・ボス次の一撃必中）、別の独立20%で**原初の壊撃**（通常命中率10%、ダメージ×10）。同時発動で必中10倍も成立し、暴走中なら×15相当。
- 戦闘記録：直近30戦、全ターン（最大150）を保存。各「記録」から閲覧。
- **[未実装]** ボスごとの素材・アイテム・魔法ドロップ。`FOREST_BOSS_DROP_TABLES` は空配列。`ITEM_CATALOG` も空。

## v0.19 状態異常・特殊能力への対策

麻痺などの状態異常に対してアクセサリー耐性を実装。魔法のキュアは既存デバフ解除、リレイズは戦闘中1回だけ致死HPダメージから復活。**ねこパンチはリレイズでも防げない**。詳細・全25体の特殊行動発動率は[特殊効果管理表](status-effects.md)を参照。

### 状態異常・特殊効果

以下は現行エンジンの概要。各ボスは上記の能力セットを**毎ターン独立に抽選**し、複数同時発動する場合がある。

| 種別 | 実装挙動 |
| --- | --- |
| 毒・出血 | ターン開始時に最大HPのそれぞれ8%／5%を直接削る。**ウォール貫通** |
| 暗闇 | プレイヤーの命中抽選を0.35倍 |
| 攻撃弱体 | プレイヤーの最終攻撃ダメージ×0.55 |
| 鈍足 | 行動回数−2（最低1回） |
| 回復封じ | ヒール、再生などを含む回復処理を無効化 |
| 魔法封印 | そのターンの魔法発動抽選を行わない |
| 防御破壊 | 防御計算に使う装備防御を25%へ低減 |
| 脆弱 | 被ダメージ×1.5 |
| 麻痺 | 次のプレイヤーターン行動不可、次の敵攻撃が必中 |
| 高火力攻撃 | 基本命中率10%、敵ダメージが指定倍率（6～10倍など） |
| 貫通攻撃 | 最大HPの一定割合をウォール・防御を無視して直接減らす |
| 結界破砕 | 現在のウォール耐久値から指定割合を消す |
| 魔法搾取 | 装備中の魔法から使用回数を減らす |
| 自己再生 | ボスの最大HPの指定割合を回復（最大HPを超えない） |
| 生命吸収 | この攻撃の実HP被害の一定割合をボスが回復 |
| 異界の怒り | 一定回数の敵攻撃に倍率を加算 |

状態異常は**1戦闘の中だけ有効**。戦闘をまたぐ状態異常は未実装。通常の異世界ボスもHP50%で暴走する。

### 超レアボス：異世界に迷い込んだぴーるな

- 出現率 **0.01%**（各異世界戦闘の抽選）。それ以外の99.99%では通常25体から均等に選択。
- HP：**1**。プレイヤーの攻撃命中率：**0.001%**。ジョブ・運・ビールで上下しない。ファイアーにも同率の専用命中判定。
- 普段は**ゴロゴロ、香箱座り、ふみふみ、おててないない**などの猫の行動がログに出る。
- 毎ターン**0.05%**で、ウォール・防御無視、必中即死の「ねこパンチ」。
- 討伐：**1,000,000,000 EXP／7,400,000 G**（敵固有の基準値。運による微小Gボーナス・バンデット効果などは別途あり得る）。
- 150ターン時間切れ：基準報酬 **700,000,000 EXP／0 G**。フロラフルルはEXPにさらに1.5倍の補正がかかる。時間切れは死亡扱いではない。
- 自動周回の「遭遇停止」ONなら戦闘前に停止し、`state.isekai.pendingBossId` に出現個体のIDを保存。次回手動挑戦で消費。

### 異世界の魔法ドロップ

- **[実装済]** 異世界では勝利時に**基本1%、トレジャーハンターは5%**で魔法1個。ドロップ魔法は残り3,000回。
- **[実験ブランチ・暫定]** 当選後の6種の均等抽選を重み付き抽選に変更。[魔法の内訳と切り戻し](equipment-and-magic.md#魔法)を参照。
- 異世界の戦闘ログは直近30戦を保持。自動周回でも魔法を自動取得し、獲得内訳を記録。

## 4. 全戦闘共通の勝敗と時間切れ

- **[実装済] 150ターンが全ダンジョンの上限**。
- 時間切れ撤退なら敵の基準EXP70%（切り捨て）に職業補正を適用。獲得G0、死亡・所持G減少なし。
- プレイヤーのHP0による敗北は時間切れと異なり、EXP0、所持G10%喪失。
- **自動周回は時間切れでも必ず停止**。勝利した場合でもHP30%以下・MASTER到達等で停止する。
