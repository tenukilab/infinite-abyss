# 通常迷宮モンスター管理台帳 — v0.22

> **[実装済・数値は暫定]** 2026-11-22更新。現行 `index.html` の `MAIN_FAMILIES` / `MAIN_PHASES` と数値計算式に基づく200種の台帳。図鑑ID `main:foe:名前` はセーブの記録に使うため無断変更不可。

## 仕様

- 既存の通常迷宮1〜5層（ボス「腐敗した騎士」含む）を維持し、**6〜50層に新モンスター200種**を配置。
- **20系統の種族 × 10テーマの変異**。モンスターごとに固有名・HP・攻撃パラメータ・EXP・G。1層につき4種、ただし偶数層6〜44は5種。
- **第5層の腐敗した騎士討伐で第6層解放**。既存セーブがボス討伐済みなら読み込み時に第6層を解放。第6〜49層は各3勝で次層を解放。50層が現状の最深層。
- 追加雑魚敵には**状態異常や特殊技を付与しない**。ダンジョンの既存報酬と150ターン撤退・自動周回停止条件をそのまま使う。
- 通常迷宮の図鑑は**従来19種＋200種＝219種**。魔の森11種、異世界26種を含めた図鑑総数は**256種**。通常迷宮は10層単位で図鑑を閲覧。
- 名称・HP・EXP/G・モンスターIDはセーブ済み図鑑と連動するため、後から変更する場合は互換性を検証する。

## 調整用成長曲線

`d=(層-6)/44` とした指数補間。種族係数は `MAIN_FAMILIES` に保持する（数値はすべて仮）。

| パラメータ | 基礎計算式 |
| --- | --- |
| HP | `round(380 × 14000^d × 種族HP係数)` |
| 攻撃配列値（atk） | `round(110 × 32^d × 種族攻撃係数)` |
| EXP | `round(145 × 960^d × 個体EXP係数)` |
| G | `round(100 × 340^d × 個体G係数)` |

攻撃配列値 `atk` は敵の最終攻撃ダメージそのものではなく、`monster()` で `str` に変換される元の値。第50層の新敵は**最大HP約702万**、攻撃配列値最大3907、基準EXP約15万、G約3.65万で、異世界通常ボスの設定下限（HP1000万、str4100、基準EXP20万、G5万）を下回る。

## 実装時の注意

1. 200体を独立した手書きデータとして二重管理せず、`MAIN_FAMILIES` と `MAIN_PHASES` の生成結果から`floors[6..50]` と `CODEX_MONSTERS` を作る。
2. 名称を変える場合は `main:foe:名称` を使う既存図鑑のID互換性に注意。
3. 必ず**200件の重複なし、全50層、各層4〜5種、既存1〜5層維持、旧ボス討伐済みセーブの第6層解放**をテストする。
4. 新ボス・素材・新ドロップ・特殊効果は今回未実装。別仕様として設計・テストして追加する。
