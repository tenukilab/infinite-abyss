**[実装済・数値は一部暫定]**

| 職業 | 効果 |
| --- | --- |
| 戦士 | 不屈の闘志：HP50%以下で与ダメージ×1.25 |

| 重騎士 | 金剛の守り：HP50%以下で被ダメージをさらに35%軽減 |
| フェンサー | 剣舞：すべての攻撃ダメージ×1.2 |
| 魔術師 | 秘奥の魔力：魔力暴走の倍率を×2.5→×4 |

## 注意・改変チェック

1. ジョブ表示名と内部IDは分ける（旧セーブ互換）。
2. スキルは命中時に**1回の攻撃につき最大1種類**。魔法は**1ターン最大1回**。
3. 総合LvUPの能力値はその瞬間のジョブにより永久加算。転職時の再計算・倍率補正は禁止。
4. マスターパッシブは現ジョブ限定。他ジョブに切り替えたとき発動しない。
5. 新ジョブ追加時は `jobKeys`・`levelGrowth`・`skills`・`jobRequirements`・ショップ名と商品・既存セーブ移行を同時確認。
