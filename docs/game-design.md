# ゲーム基本仕様（v0.23）

## 目的・プレイヤー体験

**[実装済]** iPhone Safariでも動く、単一HTMLのブラウザRPG。キャラクターを育ててダンジョンを周回する。基本はオート戦闘だが、転職・装備・魔法・進入先・周回条件の選択によって攻略法を作る。強いボスに対しては、火力一辺倒でなく耐久・壁・回復・対策ビルドの余地を持たせる。

ゲームは `index.html` 単体で動作。通信やログインは不要。セーブはブラウザのローカルストレージ。

## 育成

- **[実装済]** 6能力値：力 `str`、魔力 `mag`、生命力 `vit`、器用さ `dex`、素早さ `agi`、運 `luk`。
- 総合Lv上限は**1,000,000**。ジョブLv上限は**60**で、到達すると**MASTER**になる。上級職の資格は[ジョブツリー](job-tree.md)を参照。
- 総合経験値は共通。ジョブ経験値・ジョブLvは職別。戦闘経験値は総合と現在のジョブの両方に加算。
- 総合Lv100,001以降は、新しく総合Lvが1上がるごとに**育成ポイント1**を得る。総合Lv100,000から既存のキャラクター詳細で残数を確認できる。ポイントの割り振り画面と交換レートは未設計。
- **レベルアップ時に現職に対応する `levelGrowth` の値を永久加算**。整数部は確定、端数は確率で+1。
- 転職時は総合Lv、永続能力値、保存済みの現在HP・HP成長量、装備、熟練度、旧ジョブの育成データを引き継ぐ。通常迷宮の現在階層カーソルは第1層へ戻る。
- 装備・強化補正を足した6能力値は各**20,000**までを通常の計算・表示に使う。通常最大HPは `50 + 生命力×4 + hpGrowth` を**10,000,000**まで使う。総合LvUP時のHP成長や戦闘内の職業補正は[ダメージ計算仕様](damage-calculation.md#1-派生値装備hp)を参照。
- ジョブ定義の旧 `jobs[*].growth` ではなく、現在のLvUP処理は **`levelGrowth`** を使う。混同しないこと。
- マスター専用パッシブはマスターした職に現在就いている間だけ有効。転職条件には取得済みMASTERを利用。

## 状態異常への対策（v0.19）

**[実装済・数値は暫定]** アクセサリーの装備枠1つに、麻痺耐性・毒/出血耐性・封印/弱体耐性の3種類の共通装備を用意。装備中の耐性は、敵の状態異常が発動したあとに別抽選で付与を無効化する。既存のオーラの結晶（熟練技発動率3倍）との同時装備は不可。

魔法に**キュア**（発動後に既存のデバフを解除）と**リレイズ**（発動済みなら戦闘中1回だけ致死HPダメージから最大HP30%で復活）を追加。キュア発動前の毒ダメージは巻き戻らず、魔法封印・麻痺中は魔法自体が使えない。**ねこパンチの必中即死はリレイズ無効**。各効果の定義は[特殊効果管理表](status-effects.md)を参照。

## 戦闘：主な式

> **厳密な計算順序・端数処理・上級職の倍率・防御・ウォール・直接HP被害は [ダメージ計算仕様](damage-calculation.md) を参照。** 以下は概要であり、それ単独での再実装には使わない。

**[暫定実装]** 数値は現在の計算式。ゲームバランス調整対象。

- 通常攻撃の基礎威力 = **2 + (物理なら力／魔法型なら魔力)×2.05 + 装備攻撃**。
- 上記に乱数係数・ジョブスキル倍率をかけ、その後魔力暴走・武器熟練技「極撃」・ビール・マスターパッシブ・状態異常の倍率などを適用。
- 装備攻撃 = 武器の基本攻撃 + **武器熟練×5**。レーヴァテインは **12,000+2,000×5=22,000**。
- 物理/術攻撃の基本命中率 = `clamp(82 + 0.65×(攻撃者の器用さ−対象素早さ) + 0.23×(運差), 52, 98)`（職業補正等を適用する前）。弓使い+10pt、フェンサー+5pt、アーチャー+15ptなどは最大99%。
- 基本攻撃回数 = **1 + min(3, floor(素早さ/20))**。マスターシーフ、曲芸師は+1（最大5回の構成が可能）。
- ジョブスキル：現在のジョブLvで解放されたスキルを高Lv側から抽選し、**成功した攻撃1回につき最大1種類**。素の発動率 + 運×0.18pt、上限85%。
- 魔力暴走：魔法使い・魔術師の命中時パッシブ。運に応じた抽選、基礎2.5倍、マスター時はそれぞれ3.5倍／4倍。
- 敵ダメージ計算は `foe.str` と装備防御、職業パッシブ、ガード、ボス暴走・大技、状態異常などを順次反映。装備防御は各部位の和、玄武の鎧は **2,500+熟練2,000=4,500**。
- 敵の直接HP攻撃・毒・出血・ねこパンチなどには通常のウォール吸収が適用されないケースがある。効果ごとに実装を参照。

## 戦闘結果

- **[実装済]** すべての戦闘は**最大150ターン**。
- 敵HPが0なら勝利：EXP・G・熟練EXPなどを獲得し、異世界ではドロップ抽選。
- **150ターン終了で敵が生存**したら「時間切れ撤退」：**敵EXPの70%（切り捨て）／Gなし**。敗北数は増えず、所持金は減らない。
- プレイヤーHPが0の敗北：EXPなし、所持Gの10%（切り捨て）喪失、現在HPは通常最大HPの25%（切り上げ）へ復旧。ダンジョンごとのカーソル処理が発生。
- 武器・胴防具の熟練EXPは**戦闘終了時に1～4**。現在の実装は勝敗・撤退でも増える（熟練上限に達していなければ）。
- 通常迷宮・魔の森・異世界は同じ `fightOne()` の戦闘エンジンを使う。魔の森・異世界は直近30戦の全ターン記録を保持。

## 自動周回（v0.20）

**[実装済]** 通常迷宮・魔の森・異世界に対応。1～**1,000戦**を指定し、ブラウザを表示中に1戦ずつ処理。

初期設定：1,000戦、最大HP**30%**以下で停止、ジョブMASTER到達停止ON、敗北・時間切れ停止（固定）、ボス再戦許可ON。異世界のみ「ぴーるな遭遇時停止」が初期ON。

- 各戦闘の開始前後にHP撤退条件・MASTER・目標数を確認。**敗北と150ターン撤退は必ず停止**。敗北を回避できる保証はない。
- 異世界では毎戦ボスを抽選。ぴーるな遭遇停止ONなら**戦闘前に停止**し、遭遇ボスIDをセーブに保存。次回手動戦闘で同じ相手を使用。
- ボス許可OFFの扱い、通常迷宮ボスの再戦不可などは `startAutoRun()` と `runAutoStep()` を参照。
- **毎戦の戦闘結果はセーブ**。手動停止・画面非表示・再読み込みで自動周回は中止され、勝手に再開しない。
- **未実装**：自動宿屋、自動転職、オフライン中の自動戦闘、周回中の勝手な階層移動。

## 実装中に守るべき約束

プレイヤーが転職しただけで能力値・装備を変えない。150ターン撤退を勝利や死亡として扱わない。異世界のレアボス出現率を「26体均等抽選」に変更しない。勝手な自動宿屋・自動転職・バックグラウンド処理を追加しない。

## モンスター・魔法図鑑（v0.20）

**[実装済]** 全56種の敵と6魔法を収録。未遭遇は「？？？」表示、遭遇後に敵能力と戦績を開示。図鑑の状態は `state.codex` に永続保存し、旧セーブの戦闘記録から復元可能な分だけ引き継ぐ。詳細な保存構造とID維持条件は [図鑑仕様書](encyclopedia.md) を参照。

## v0.22 通常迷宮深層の拡張

**[実装済]** 通常迷宮を全50層へ拡張。第1〜5層の従来敵と第5層ボスは保持。討伐済みボスから第6層を解放し、第6〜49層は3勝ごとに次層を開放。新200種を20種族×10環境変異で構成。各層4〜5種、最深層でも異世界の通常ボス未満の仮数値。図鑑全256種。モンスター別数値は [通常迷宮200種管理台帳](normal-dungeon-monsters.md) に記録。戦闘ロジック、セーブキー、150ターン撤退と自動周回停止は変えていない。
