# 決定事項・未実装・開発方針（v0.22）

> 2026-11-22時点。**実装済**と**構想**を混同しないための管理表。
> 企画の方向性はユーザーが決定し、AIは必要な仮数値を提案・実装する。仮値は後で調整可能。

## 1. ゲームとして守る決定事項

| 項目 | 決定内容 | 状態 |
| --- | --- | --- |
| 転職 | LvUP時のジョブで永久能力値が上がる。**転職しただけでは6能力値・HP・装備が変動しない** | [実装済] |
| 装備制限 | 通常装備は職業制限なし。例外的な専用装備は後で追加 | [実装済]＋例外は[構想] |
| 熟練 | 武器熟練+1で攻撃+5、胴熟練+1で防御+1、レーヴァテイン22,000／玄武4,500 | [実装済] |
| オーラの結晶 | アクセサリー装備で熟練技15%→45%。旧開発用データに付与 | [実装済] |
| ウォール | 戦闘ごとに壁最大HP×3まで。魔法店に販売しない。異世界ドロップ対象 | [実装済] |
| ジョブマスター | 各職Lv60でMASTER。上級職解放条件に下級MASTERを利用。マスター効果は現在の職だけ | [実装済] |
| ボス | HP50%以下で暴走（原則×1.5）。魔の森50階は麻痺20%・壊撃20% | [実装済] |
| 異世界 | 階層なし。通常ボス25体、特殊効果を複合。勝利で魔法1%ドロップ | [実装済] |
| ぴーるな | 正式名「異世界に迷い込んだぴーるな」。0.01%出現、攻撃命中0.001%、0.05%ねこパンチ | [実装済] |
| 全戦闘 | 最大150ターン、倒せないならEXP70%・G0の時間切れ撤退 | [実装済] |
| 自動周回 | 最大1,000戦。**時間切れ撤退でも停止**。ぴーるな遭遇停止は任意 | [実装済] |
| 保存 | 旧セーブを保持し、現在の育成・装備・魔法の履歴を守る | [実装済] |
| 図鑑 | モンスター**256種**（通常迷宮219、魔の森11、異世界26）・魔法6種。遭遇・討伐・敗北・撤退・ドロップを永続保存 | [実装済] |
| UI整理 | メイン4項目（冒険・育成・図鑑・その他）、詳細を折りたたみ、ダンジョン滞在中の参照を許可（操作は拠点） | [実装済] |
| 通常迷宮の増設 | 旧5層と腐敗した騎士を保持し、**全50層へ拡張・新通常敵200種**を実装。既存ボス撃破セーブは6層解放。数値は異世界ボス未満の仮バランス | [実装済・暫定値] |

## 4. 新しい開発依頼を受けたときのルール

1. 直近の指示が表の仮値と矛盾したら、新しい指示を優先する。
2. 決定済み仕様は**「確定」**、試行用に置いた数値は**「暫定」**、提案止まりは**「構想」**と区別する。
3. 実装前に関連文書と `index.html` を確認。新機能を作ったらこの表と対応する台帳を変更する。
4. 仕様が既存セーブに触れる場合、ユーザーデータ維持を最優先。
5. 決定済みの実装を台帳へ反映する。未実装の構想はユーザーの合意なく勝手に実装しない。
