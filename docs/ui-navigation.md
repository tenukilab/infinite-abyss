# UI設計・ナビゲーション（v0.22）

> 状態：**[実装済]**。対象：iPhone Safariを優先する単一HTML版。ゲームバランス・戦闘仕様の変更なし。
> 実装：`index.html` の `renderHero()`、`adventureHubHTML()`、`magicOverviewHTML()`、`render()`、`travel()`、クリックイベント処理。

## 1. 4つのメインメニュー

**どの場所に滞在していても同じ4項目を表示**する。初期画面では「冒険」、カジノ滞在セーブを開いた場合は「その他」。

| メイン | サブ画面／機能 | 設計ルール |
| --- | --- | --- |
| ⚔ 冒険 | 通常迷宮・魔の森・異世界、戦闘・自動周回 | 現在滞在している場所の冒険画面を表示。拠点から森・異世界へ直接移動できる |
| ◇ 育成 | 装備／ジョブ／魔法 | ダンジョン滞在中でも**閲覧可能**。転職、装備変更・売却、魔法の購入・装備・回復・合成は拠点で行う |
| 📖 図鑑 | モンスター・魔法図鑑 | どこからでも閲覧可能。発見情報と保存済み戦績を表示 |
| ☰ その他 | 拠点施設／冒険記録・セーブ／カジノ島 | 拠点の店・宿・鍛冶は実際に拠点へ帰ってから。カジノは拠点から渡航する |

### 冒険の導線

- 拠点滞在中：**通常迷宮（現在）／魔の森／異世界**をカード表示。森・異世界へボタンで入場する。
- 森・異世界滞在中：現在のダンジョン画面と「拠点へ戻る」を表示。育成・図鑑・その他へ切り替えても戦闘場所は変わらない。
- カジノ島滞在中：冒険タブに帰還案内と「拠点へ戻る」を表示。カジノ本体は「その他」で利用。
- 拠点へ戻る操作だけが `state.location` を `main` に書き換える。閲覧用のタブ切り替えでは書き換えない。

### 育成のサブメニュー

- **装備**：装備中の6枠を先に表示。所持品一覧は折りたたみで確認。拠点以外では装備・売却ボタンを出さない。
- **ジョブ**：下級6職、中級7職、複合9職、特別職グランドマスターを表示する。表示するMASTER数はこの23職の達成数。通常パッシブとMASTER効果を職業カードで確認できる。勇者は通常2枠、グランドマスターは通常3枠を個別に表示する。上級職の一覧と資格は通常画面の表示対象外。拠点以外では閲覧のみ。
- **魔法**：現在の魔法枠と所持魔法・魔法器を一覧化。拠点にいる場合のみ「魔法店を開く」で「その他 → 拠点施設 → 魔法店」へ移動する。
- **その他 → 拠点施設**：武器屋／防具屋／アクセサリー店／魔法店／宿屋・鍛冶屋とカジノ渡航を維持。機能自体は従来どおり。

## 2. キャラクター情報（コンパクトヘッダー）

- 常時表示：ジョブ名とジョブLv、キャラクター名、総合Lv、**現在HP／最大HP・HPバー**。通常画面のHP・能力値は[通常計算の上限](damage-calculation.md#1-派生値装備hp)を適用した値。
- タップで展開：総合EXP／ジョブEXPバー、6能力値、装備攻撃・装備防御、熟練技発動率、命中・回避・行動回数。
- 総合Lv100,000以上では、展開したキャラクター詳細に育成ポイントの残数を表示する。
- `<details id="heroDetails">` の開閉状態は画面更新時にも維持。閉じた状態を初期表示。
- 画面の上部に位置する4項目ナビは、スクロール中も利用可能なsticky形式。小画面で文字を詰めた6項目を置かない。

## 3. ゲーム状態とUI状態の分離

**最も重要：閲覧のための画面切替をゲーム進行と混同しない。**

- **ゲーム保存対象**：`state.location`（`main` / `forest` / `isekai` / `casino`）、戦績、進行、装備、魔法、職業、図鑑。これらは従来の `localStorage` に保存。
- **画面専用の一時状態**：`uiSection`（`adventure` / `build` / `codex` / `more`）、`buildTab`（`gear` / `jobs` / `magic`）、`moreTab`（`town` / `record` / `casino`）、折りたたみの開閉状態。**セーブに新フィールドを追加しない**。
- 既存 `tab` は表示する実ページとの互換目的で維持。特に `magicShopAccess()` は **`state.location==='main' && tab==='town' && townSection==='magic'`** に依存する。勝手に緩和しない。
- `travel(destination)` は実際の移動時のみ `state.location` を変更して冒険ログとセーブを更新。タブ切替はゲーム状態に副作用を起こさない。
- 自動周回中は従来どおり停止操作を優先し、ほかの操作を受け付けない。
- セーブキーは **`infinite-abyss-save-v5`、`VERSION=5`** のまま。JSONの入出力も維持。

## 4. 維持するゲームルールと操作

- 通常迷宮の戦闘、魔の森50階、異世界26体のランダム戦闘とぴーるな遭遇の扱いは一切変更しない。
- 150ターン時間切れ撤退は敵EXP70%・獲得G0。自動周回は時間切れでも停止。
- 転職時に保存済みの6能力値・装備・HPを維持する。上級職のセーブでは今のジョブがヘッダーに表示され、そのジョブを離れるときは確認を出す。
- カジノ、ショップ、魔法合成／回復、装備の熟練度、図鑑は既存処理を使用。
- [要注意] ダンジョン内で育成画面の情報を**見せる**ことと、育成や店の操作を**許可する**ことは別。閲覧可能にしたからといって位置制限を撤廃しない。

## 5. 回帰テスト

**[確認済]** 2026-11-22、Node.js構文検査とChromium/Playwrightで以下を検証。

- スマホ幅 **375 / 390 / 430px**、横スクロールなし、4メニュー・各サブページを操作可能。
- 冒険⇄育成⇄図鑑⇄その他の切替でセーブ値が**不変**。
- 魔の森・異世界・カジノへの移動、ダンジョン内で装備/ジョブ/魔法/図鑑の閲覧、拠点への帰還。
- ダンジョン滞在中の装備変更／転職のUI上での禁止。
- キャラクター詳細と装備一覧の折りたたみ、当時の旧上級7職グループの展開。
- 魔法店への遷移と購入、図鑑への反映、手動戦闘、10戦自動周回、セーブの再読み込み。
- ジョブ13職、図鑑56種、戦闘150ターン上限の既存定数を維持。

### 将来の画面追加方針

新システムを追加するときは**先に4メニューのどこへ入れるか**決め、必要ならサブメニューを追加。トップレベルの項目数をむやみに増やさない。UI専用状態をゲームのセーブへ持ち込まない。

## v0.22 通常迷宮50層のナビゲーション

- 迷宮画面の層選択は `1〜10 / 11〜20 / 21〜30 / 31〜40 / 41〜50` の5帯に分けた。まだ到達していない帯への切替は不可。
- それぞれの帯は最大10層のボタンを表示。現在層、解放層、未解放の状態を示す。
- 第5層ボス討伐後に第6層を開き、6〜49層では3勝で次層を開く。第50層は最深層。
- 図鑑の通常迷宮も10層帯を選んで表示する。図鑑全256枚を一度に描画しない。
- 層帯選択と図鑑の層帯選択は一時的なUI状態（`mainFloorBand` / `codexMainBand`）。階層移動のみゲーム保存の `state.floor` を変更する。

魔法の所持一覧は育成画面と魔法店で同種を「×個数」と表示する。開くと個体ごとの使用残数・装備・封入状況を確認できる。魔法店の装備・回復などの操作は個体ごとに行う。
