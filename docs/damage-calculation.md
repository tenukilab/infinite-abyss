# ダメージ計算・命中・防御の厳密仕様（v0.23 実装準拠）

> **状態：[実装済の動作をコードから抽出]／バランス数値：[暫定]**
>
> 検証基準：2026-11-23時点の `index.html` v0.23。根拠関数：`derived()`、`accuracy()`、`playerAccuracy()`、`rollSkill()`、`fightOne()`、`powerValues()`、`masteryProcRate()`。
>
> **注意：これは現行実装の計算順序を忠実に記録した「現状仕様」。未決定の理想仕様を勝手に確定しない。** 一箇所の倍率変更だけでも他の効果と合成した結果が変わる。改修時は本書・コード・回帰テストを同時に更新すること。

## 0. 用語と数値形式

- `R(x)=Math.round(x)`：JavaScriptの四捨五入（正数の .5 は切り上げ）。
- `C(x)=Math.ceil(x)`：切り上げ。`F(x)=Math.floor(x)`：切り捨て。
- `clamp(x,min,max)`：値を上下限内に収める。
- `rand()`：保存セーブ内の `state.rng` を進める疑似乱数、範囲 [0,1)。`ri(a,b)` は両端を含む整数乱数。
- **攻撃パラメータ（STR等）・装備基本攻撃・「計算したダメージ」・「実HPダメージ」は別の値**。敵HPを超える超過ダメージは実HPダメージに含めない。
- 以下の確率では、`rand()*100 < p` は **p%**、`rand() < q` は **確率q（q×100%）**。同じ0.2でも20%か0.2%か混同しない。
- **重要：各倍率の間で `R`、`C`、`F` を個別に実行する。すべての倍率を先に掛けて最後に一度丸める式と同等ではない。**

## 1. 派生値（装備・HP）

1. `derived()` で永続能力値 `baseStats` に、装備6枠の各 `stat` 補正と強化ボーナスを足す。武器強化は製造元ジョブ等から判定した力/魔力、その他装備強化は生命力に加算。
2. `baseAttack = Σ(各装備の baseAttack + [武器のみ mastery×5])`。
3. `baseDefense = Σ(各装備の baseDefense + [胴のみ mastery×1])`。
4. `normalMaxHP = 50 + 4×派生生命力 + hpGrowth`。ガーディアンは `F(normalMaxHP×1.5)`、ダークナイトは `F(normalMaxHP×1.2)`。それ以外は `normalMaxHP`。
5. **転職だけで永続能力値・現在HP・装備・熟練値を再計算・リセットしない**。最大HPの派生値のみ新ジョブの効果で変わり得る。

## 2. プレイヤーの命中判定

### 通常敵

```text
基礎命中率(%) = clamp(82 + 0.65×(自DEX − 敵AGI)
                        + 0.23×(自LUK − 敵LUK), 52, 98)
職業補正後(%) = 弓使いなら min(99,基礎+10)
                 アーチャーなら min(99,基礎+15)
                 フェンサーなら min(99,基礎+5)
                 それ以外なら基礎
戦闘時命中率(%) = 職業補正後 × (ビール中なら0.5) × (暗闇なら0.35)
判定：rand()*100 < 戦闘時命中率
```

- **命中が先、スキル・魔力暴走・極撃は命中後の抽選**。外れた攻撃ではスキルや攻撃倍率は発動しない。
- 1ターンの基礎攻撃回数 `1+min(3,F(AGI/20))`。MASTERシーフまたは曲芸師は+1。鈍足なら−2（最低1）、麻痺中は0。
- **ぴーるなだけ例外**：物理攻撃もファイアーも命中は **0.001%固定**。器用さ・運・ビール・暗闇などの補正で変化させない。
- プレイヤー攻撃は `1〜5回` の各回で個別に命中判定を行う。

## 3. プレイヤーの攻撃ダメージ：厳密な処理順

通常攻撃／スキル／熟練技は、**命中した1攻撃ごと**に次の順で算出。

### 3-1. 基本攻撃を作る

```text
raw = 現ジョブmodeが magic なら派生MAG、その他なら派生STR
基礎値 = 2 + raw×2.05 + 装備baseAttack
乱数 = 0.90 + rand()×0.20 + min(0.06, 派生LUK/700)
攻撃値 = max(1, R(基礎値 × ダークナイト自傷倍率
                      × ギャンブラー累積倍率 × 乱数 × スキル倍率))
```

- スキル倍率：命中後、**習得済みスキルをLvの高い順に判定**。最初に当選した1個の `power`、なければ1。
- 各スキルの当選率：`clamp(基本発動率 + LUK×0.18, 0, 85)%`。最上位から順に判定するので、選択割合は単純な基本発動率ではない。
- ダークナイト自傷倍率：**攻撃試行ごとに独立20%**。当選した攻撃だけ **×20**。さらに命中判定の前に、`F(その時点の現在HP×0.5)` を消費（HPは最低1残す）。**攻撃を外しても自傷は発生済み**。
- ギャンブラー累積倍率：各ターン冒頭に `stack = stack × (0.3 + rand()×2.7)`（最初は1）。**前ターンまでの値を保持して乗算し、同ターンの全攻撃へ適用**。現状、倍率の下限/上限や数値桁数制限はない。戦闘終了で1に戻る。
- 上記の最初の `R` は一度だけ。以降の倍率は**適用するたび別個に丸める**。

### 3-2. 命中後の倍率（適用順を変えない）

| 順位 | 条件・処理 | 算式／丸め |
| ---: | --- | --- |
| 1 | 魔法使い・魔術師の魔力暴走 | `rand()*100 < clamp(10+LUK×0.15,10,45)`。当選時 `R(hit×2.5)`、現職MASTERなら魔法使い×3.5／魔術師×4 |
| 2 | 武器熟練技「極撃」 | 熟練50以上。確率は通常15%、オーラの結晶で×3、ウェポンマスターならさらに×1.3。`R(hit×(5×熟練段階))`、段階 `min(10,F(武器熟練/50))` |
| 3 | ビール | 使用済なら `R(hit×1.2)`。賢者は `R(hit×1.4)` |
| 4 | 戦士MASTER・HP50%以下 | `R(hit×1.25)` |
| 5 | 弓使いMASTER「弱点看破」／アーチャーMASTER「鷹の眼」 | 条件当選時 `R(hit×2)` または `R(hit×2.5)` |
| 6 | フェンサーMASTER「剣舞」／曲芸師MASTER「連舞」 | `R(hit×1.2)` |
| 7 | 攻撃弱体状態 | `max(1,R(hit×0.55))` |
| 8 | ウェポンマスター | `R(hit×2)` |
| 9 | 武士 | 命中した攻撃ごと20%で `R(hit×ri(10,50))` |
| 10 | ダークナイトの攻撃強化 | 命中した攻撃ごと30%で `R(hit×1.2)` |

**補足：** 職業固定なので、魔力暴走・ウェポンマスター・武士・ダークナイト等の相互同時発動は通常ない。一方、装備熟練技・ビール・スキル・状態異常との合成はあり得る。

### 3-3. 実ダメージ／HP吸収／追加効果

```text
実際に減る敵HP = min(攻撃前の敵HP, hit)
敵HP更新      = max(0, 敵HP − hit)
```

- 戦闘ログに表示される `hit` は超過分を含むことがある。ダークナイトの吸収（命中後20%）とスキルのドレインは**実際に減った敵HP**を基礎に計算する。
- `heal`・`drain` は `recover()` を通るため、**回復封じ中は回復しない**、最大HPを超えて回復しない。回復量は `F` で整数化。
- `stun` スキルが命中したターンは敵の反撃を止める。`guard` スキルは同ターンに発動した最大の軽減率を記録し、後述の敵通常攻撃に反映。
- HPが0になった敵にはそのターンの敵反撃は発生しない。

## 4. 魔法の直接ダメージ・壁・回復

- **1ターン最大1魔法**。ターン開始時の魔法抽選が通ったら、通常攻撃より前に発動する。麻痺・魔法封印中は抽選しない。
- **ファイアー**：通常敵へ**固定500ダメージ**（賢者なら固定1000）。命中・攻防・スキル・極撃・最終攻撃倍率による補正は**ない**。ぴーるなだけ別途0.001%固定命中判定。
- **ウォール**：最大HP相当の壁を追加、賢者なら最大HP×2を追加。**壁全体の上限は最大HP×3**。防御と軽減を終えた敵通常攻撃ダメージを壁が吸収し、残りだけHPへ通す。
- **ヒール**：HP+300、賢者はHP+600。上限は最大HPで、回復封じに従う。
- **リレイズ**：発動後にHPが0以下になった際、戦闘中1回だけ復活（通常は最大HPの30%、賢者なら60%を `C`）。ねこパンチだけ復活不可。
- **キュア**：状態異常を解除。ただしターン冒頭の毒・出血ダメージをさかのぼって回復させない。
- **賢者の発動率**：魔法器の倍率を含む通常発動率を計算した後、さらに×2して最大100%に制限。各装備魔法の残り使用回数が1以上なら、各ターン1〜3回復する（0からは復帰しない）。
- ファイアーは**固定ダメージ処理**で、プレイヤーの攻撃ダメージ計算式には通さない。

## 5. 敵の通常攻撃：命中・防御・ダメージの厳密な順序

### 5-1. 敵の命中率

```text
通常命中率(%) = clamp(82 + 0.65×(敵DEX−自AGI)
                         + 0.23×(敵LUK−自LUK),52,98)
優先順位：麻痺等による次攻撃必中 → 100%
          異世界 heavy の命中上書き → 10%
          魔の森50階「原初の壊撃」 → 10%
          それ以外 → 通常命中率
判定：rand()*100 < 決定した命中率
```

- **必中フラグは次の敵攻撃判定1回で消費**。異世界の大技と麻痺が同時当選した場合も必中が優先。
- ガーディアンは、**命中した敵の通常攻撃をさらに30%で完全無効化**。命中判定後、ダメージ算出前に抽選。
- 敵の行動前にプレイヤーが敵を倒した、スキルのスタンで反撃阻止した、あるいは麻痺処理で反撃が省略された場合、通常攻撃を受けない。

### 5-2. 防御力による減算と通常ダメージ

```text
防御有効倍率 = 防御破壊状態なら0.25、通常は1
階層補正 = 魔の森なら 階数×3 ／ それ以外なら 階層数×2
            （異世界は通常 f=0）
防御適用前の内部値 = max(1, 4 + 敵STR×1.35 + 階層補正
                           − 装備baseDefense×防御有効倍率)
敵の攻撃乱数 = 0.90 + rand()×0.20
enemyHit = max(1, R(防御適用前の内部値 × 敵の攻撃乱数))
```

**装備防御力は乗算軽減ではなく、敵の攻撃式から先に引く。** 防御破壊は減算する防御力を25%まで弱める効果。

### 5-3. 敵の攻撃への軽減・増幅（厳密な順序）

| 順位 | 条件 | 算式／丸め |
| ---: | --- | --- |
| 1 | そのターンのジョブスキル `guard` | `max(1,C(enemyHit×(1−guard%)))` |
| 2 | ナイト「守護」 | `max(1,C(enemyHit×0.90))` |
| 3 | 重騎士「重装防御」 | `max(1,C(enemyHit×0.80))` |
| 4 | ナイトMASTER、HP50%以下 | `max(1,C(enemyHit×0.70))` |
| 5 | 重騎士MASTER、HP50%以下 | `max(1,C(enemyHit×0.65))` |
| 6 | ボス暴走・敵HP50%以下 | `max(1,R(enemyHit×1.5))` |
| 7 | 魔の森50階「原初の壊撃」 | `max(1,R(enemyHit×10))` |
| 8 | 異世界「異界の怒り」 | `max(1,R(enemyHit×指定倍率))` |
| 9 | 異世界「滅殺の一撃」 | `max(1,R(enemyHit×指定倍率))` |
| 10 | 異世界の「脆弱」 | `max(1,R(enemyHit×1.5))` |

- 魔の森・異世界の**ボスはHPが初めて50%以下になった直後から暴走状態**になり、以後の敵通常攻撃×1.5。ぴーるなは猫の特別行動処理で通常攻撃を行わない。
- 異界の怒りの残り攻撃回数・最大倍率の計算、特殊能力の発動抽選は `fightOne()` の状態管理に従う。
- ナイト・重騎士の軽減は相互排他的だが、それぞれのMASTER条件とスキルガードは重なる可能性がある。
- **最後に** `wallAbsorb=min(現在の壁,enemyHit)`、`HP被害=enemyHit−wallAbsorb`。壁を減らし、HPからHP被害だけ引く。
- 敵の生命吸収は**壁を差し引いた実HP被害**に係数を掛け、敵最大HPを超えない範囲で回復する。
- 胴防具の熟練技「再生」は**敵からの被害処理後、生存している場合**に抽選。発動率は通常15%、オーラの結晶×3、ガーディアン×1.3。回復量 `C(最大HP×(熟練段階×10%))`、回復封じと最大HPの上限を適用する。

## 6. 通常攻撃式を通らない直接HPダメージ

| 原因 | 数値・処理 | 防御・ウォール | 特例 |
| --- | --- | --- | --- |
| 毒 | ターン冒頭、`C(最大HP×0.08)` | 無視 | リレイズ発動済みなら復活可能 |
| 出血 | ターン冒頭、`C(最大HP×0.05)` | 無視 | 毒と合算して処理 |
| 異世界の「魂への直撃」 | `max(1,C(最大HP×power))` | 無視 | ガーディアン30%で無効化。リレイズ可能 |
| ダークナイトの自傷 | 攻撃試行前に `F(現在HP×0.5)` を消費 | 無視 | **残HPは最低1**。命中失敗しても消費 |
| ぴーるなの「ねこパンチ」 | 敵反撃時、0.05%でHPを0にする | 無視・必中 | **リレイズ不可・ガーディアン30%も無効** |

**注意**：「状態異常完全無効（フロラフルル）」は毒や出血などの**付与を防ぐ**が、敵の直接攻撃・ねこパンチや自傷を無効にする仕組みではない。

## 7. 戦闘のターン順と勝敗への影響

1. ターン開始：異世界の既存状態異常の適用・毒出血ダメージ → 致死ならリレイズ判定。
2. ギャンブラー累積倍率更新、賢者の魔法回数自然回復、職固有回復など。
3. 麻痺判定 → 当ターン行動回数を決める（鈍足も適用）。
4. 魔法発動抽選・最大1魔法を処理。ファイアーで敵を倒せばその時点で敵の反撃なし。
5. プレイヤー攻撃を回数分処理。命中判定・自傷・スキル・ダメージ・吸収など。
6. 敵が生存していれば反撃段階：敵特殊効果の抽選 → 命中 → 軽減／増幅 → 壁吸収 → 実HP被害／回復。
7. 敵HPが0なら勝利。プレイヤーHPが0なら敗北。**150ターン経過時に敵が生存しプレイヤーが生存なら時間切れ撤退**。
8. 時間切れは基準敵EXPの70%を切り捨て、獲得G0。フロラフルルならさらにEXP×1.5（切り捨て）。自動周回は時間切れで停止する。

## 8. 計算仕様の「未確定・要検討」事項

これらは**現在の実装で動く挙動**だが、ゲームデザインとして今後正式決定すべき箇所。勝手に修正しないこと。

1. **ダークナイトの自傷20%は現在「1攻撃試行ごと」**。1ターンに複数回発生し得る。自傷後に外れてもHPは戻らない。「1ターンごと」にするかは未決。
2. **ギャンブラーの累積倍率は上限・下限なし**。極端な連続倍率で桁が大きくなり、数値精度やバランスに影響し得る。150ターン時の最大値や制限の要否は要検討。
3. **倍率の多段丸め**：現行は各段階で丸める。全倍率をまとめた最終丸めに変更するとダメージが変わる。今後もこの処理順を正式仕様とするかは要決定。
4. **「基本攻撃」と「最終攻撃」の用語**：ダークナイトの×20とギャンブラーは基礎値に、武士・ウェポンマスターは後半のhitに適用。「魔法の固定ダメージ」には通常の攻撃倍率が付かない。
5. **高レベル域のインフレ**：総合Lv10万と複合／上級職の能力値成長を考えると、装備防御の一次減算や敵の最低1ダメージの設計は再評価が必要。
6. **原初王の麻痺**：麻痺のみ発動し大技が外れた場合、通常の敵反撃自体を行わない分岐がある。意図した難易度設計か別途確認が必要。
7. **通常HPと最大HPの再同期**：ガーディアン・ダークナイトへの転職で最大HP係数が変わるが、転職時に現在HPは維持する。現在HPと最大HPの関係をUI・回復で厳密化する余地あり。
8. **戦闘ログで表示するダメージは一部「与ダメージの計算値」**。敵の残HPを超えた部分も表示するが、吸収HP計算は実際に減らしたHPを使う。

## 9. 回帰テストの基準

- 命中前の自傷、命中後のスキル抽選、乱数、各倍率の順序と**各丸め地点**が変わっていない。
- 物理・魔法型のステータス選択、武器熟練段階、オーラの結晶、ウェポンマスターの武器技だけ×1.3、ガーディアンの胴技だけ×1.3。
- ビール／暗闇の命中補正と与ダメ補正、武士の20%・10〜50倍、ギャンブラーの毎ターン累積。
- 敵防御減算 → 軽減 → 暴走・大技・脆弱 → ウォール吸収 → リレイズ／生命吸収／再生。
- 固定ファイアー、毒・出血・魂への直撃、ねこパンチは通常攻撃計算を通さない。
- 150ターン撤退、死亡、EXP・G処理、旧セーブと職業ID、図鑑記録の維持。
