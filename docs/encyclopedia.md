# モンスター図鑑・魔法図鑑（v0.22）

> 状態：**[実装済]**。ゲーム内「📖 図鑑」から閲覧。出現率・ドロップレアリティなどの数値は今後変更され得るが、図鑑の保存IDと既存のユーザー実績は維持する。

## 1. 目的と収録範囲

プレイヤーの実績を長期的に蓄積するコレクション機能。**未遭遇は「？？？」、初遭遇で名前と基本情報を解放**する。収録モンスターは計256種。

| エリア | 収録数 | カウント単位 |
| --- | ---: | --- |
| 通常迷宮 | **219種** | 既存通常敵18種＋ボス1種、新規通常敵200種（6〜50層） |
| 魔の森 | 11種 | 通常敵6種（階層違いは同じ種として集計）＋階層ボス5種 |
| 異世界 | 26種 | 通常ボス25体＋超レア「異世界に迷い込んだぴーるな」1体 |
| **魔法図鑑** | **6種類** | ファイアー、ヒール、ビール、ウォール、キュア、リレイズ |

### v0.22 深層200種と図鑑の扱い

- 既存19種の図鑑IDはそのまま。200種は `main:foe:新しい名称` という新IDで追加し、既存の遭遇・勝利記録を上書きしない。
- 新200種を含む通常迷宮は、**10層単位の5タブ**で表示を分割。219枚を一度に描画しない。
- 未遭遇は「？？？」、遭遇時は名称・階層・HP・基準EXP/G・戦績を表示。
- 旧セーブに新モンスターの遭遇記録を創作しない。追加後の戦闘で各新種を発見する。
- 詳細一覧は [通常迷宮200種台帳](normal-dungeon-monsters.md) に記載。

### モンスターの表示

- 未遭遇：名称、HP、EXP/G、特殊能力を隠す（「？？？」）。
- 遭遇後：名前・出現地域・最大HP（魔の森通常敵は階層で変動）・基準EXP/G、**遭遇・討伐・敗北・撤退**回数を表示。
- 異世界では、特殊行動ごとの**発動率・効果・持続**も開示。詳細な敵ごとの定義は [特殊効果管理表](status-effects.md) と [敵台帳](dungeons-and-enemies.md) を参照。
- 魔法がドロップした場合、その敵から得た魔法の累計件数を表示する。魔法ドロップがない敵では表示しない。
- エリアごとの発見数と、全エリア合計の発見率（**256種中何種**）を表示。

### 魔法の表示

- 一度でも入手した魔法を「発見済み」にする。未入手は「？？？」。
- 発見済みは、名前・効果・基本発動率・入手先・**現在の所持個数・累計ドロップ数**を表示する。
- 魔法の所持数は `state.magics` から現在値を算出。累計ドロップ数は `state.codex.magics[key].drops` を使用。購入回数は図鑑導入後の記録のみ。
- 異世界勝利時の魔法ドロップ率は基本1%、トレジャーハンターは5%。実験ブランチでは当選後の内訳を[暫定のレアリティ](equipment-and-magic.md#魔法)で抽選する。既存の発見・購入・ドロップ件数は引き継ぐ。

### 「青燐の骸骨兵」の図鑑ID修正

第2層と第15層の「青燐の骸骨兵」は、`main:foe:2:青燐の骸骨兵` と `main:foe:15:青燐の骸骨兵` で個別に記録する。旧v5の読み込み・JSON復元時は、混在していた旧ID `main:foe:青燐の骸骨兵` の記録だけを初期化する。階層が不明な旧ログからこの敵の戦績は復元しない。ほかの図鑑記録、階層別討伐数、迷宮進行は保持する。旧合算記録を確認する場合は移行前のJSONを参照する。

## 2. 保存スキーマ

既存セーブキー `infinite-abyss-save-v5` と `VERSION=5` を変更しない。新しい `state.codex` を追加する。

```js
codex: {
  schema: 1,
  backfilled: true, // 旧セーブから初回復元した場合
  monsters: {
    'isekai:otherworld-peeluna': {
      sightings: 1,
      battles: 0,
      wins: 0,
      losses: 0,
      retreats: 0,
      firstBattle: null,
      lastBattle: null,
      drops: {}
    }
  },
  magics: {
    fire: { discovered: true, drops: 0, purchases: 1 }
  }
}
```

- **sightings（遭遇）**：異世界は敵の**抽選時**に記録。ぴーるな遭遇時停止は戦闘前でも記録される。通常迷宮・魔の森は戦闘終了時に記録。
- **battles（戦闘）**：勝利・敗北・時間切れ撤退を各1戦。異世界で保存した遭遇相手と後で戦っても、遭遇を二重に加算しない。
- **wins / losses / retreats**：それぞれ戦闘結果で1件加算。150ターン時間切れは `retreats`、敗北・勝利には加算しない。
- **drops**：その敵から出た魔法キーごとの累計。魔法図鑑にも同じ件数を加算。
- 魔法を買えば `discovered=true` にし `purchases` を加算。異世界でドロップすれば `discovered=true` にし `drops` を加算。
- 識別IDは不変とし、名称変更時も過去データが断絶しないようにする。通常敵 `main:foe:名前`、通常迷宮ボス `main:boss`、魔の森 `forest:foe:名前` または `forest:boss:階数`、異世界 `isekai:otherworld-* `。
- この図鑑は**プレイヤーのローカルセーブに含まれる**。アカウント・オンライン同期は未実装。JSONエクスポート／インポートで移行できる。

## 3. v0.19以前の旧セーブからの復元

**[実装済]** `upgradeState()` がセーブに `codex` がない場合に一度だけ初期化する。

- 魔の森：直近30戦の `forest.battleRecords` から可能な戦績を復元。
- 異世界：直近30戦の `isekai.battleRecords` から可能な戦績を復元。レコード内 `magicDrop` があればドロップ履歴にも反映。
- 通常迷宮：最大90件の `history` から**敵名を特定できる**戦闘結果だけ復元。階層別 `state.kills` の合計を種別に割り当てない。
- 魔法：既存 `magics` 内で所有が確認できた種類を「発見済み」にする。**購入／ドロップの取得経緯が不明なら件数を創作しない**。
- 異世界で保存中の `pendingBossId` は戦闘前の遭遇として復元する。
- 過去の全戦績が保存されているわけではない。**図鑑の復元件数と既存の累計勝利数が一致しなくても正常**。図鑑導入後は種別ごとに全件累積する。
- スキーマが存在するセーブでは復元処理を繰り返さず、再読み込みによって戦績を二重加算しない。

## 5. 追加時の運用ルール

- 新しい敵を実装したら `CODEX_MONSTERS` に安定IDで追加し、図鑑分類と固有能力表示を確認。
- **既存IDの改名・削除をしない**。大規模なID変更にはセーブ移行マップが必要。
- 新魔法を追加したら `MAGIC_CATALOG` に `kind:'spell'` を設定し、ドロッププール・図鑑を確認する。
- ユーザー実績を誤って水増ししない。後付け移行に完全な過去履歴がない場合は「復元できた分のみ」と記す。
- 自動周回も手動戦闘も同じ記録関数を通す。勝利時だけ図鑑を更新する設計にしない。
- UIの「？？？」を意図せず消さない（ぴーるなを含む未遭遇シークレットを保持）。
- **戦闘テスト**：通常迷宮・魔の森・異世界、150ターン撤退、敗北、魔法ドロップ、ぴーるな遭遇停止、旧セーブ移行、再読み込み、iPhone幅。
